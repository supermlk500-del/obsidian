# Codex / ChatGPT 桌面应用侧边栏显示异常排查记录

## 1. 问题概述

在 Windows 上使用 Codex / ChatGPT 桌面应用时，应用的外观显示异常。

主要表现为：

- 使用浅色主题时，左侧设置栏出现大面积黑色背景；
- 侧边栏静止和滚动时，显示状态不一致；
- 滚动侧边栏后，部分区域会重新绘制，但仍可能出现背景错乱；
- 深色主题下也存在类似现象，只是因为背景颜色接近，视觉上不如浅色主题明显；
- 右侧主内容区域通常正常，异常主要集中在左侧侧边栏。

## 3. 初步判断

由于异常能够被 Windows 截图完整捕获，因此问题大概率不在显示器面板、背光、排线或坏点等物理硬件层面。

更可能的原因包括：

1. Codex / ChatGPT 桌面应用的界面重绘异常；
2. Windows 图形合成或 GPU 硬件加速异常；
3. 核显与独显之间的应用分配不合适；
4. 显卡驱动与应用渲染路径兼容性问题；
5. HDR、DPI 缩放或窗口化应用优化对渲染产生影响。

从“滚动后界面状态发生变化”这一现象看，问题较符合应用界面重绘或 GPU 合成异常的特征。

## 4. 设备与显示环境

本次排查时的显示环境如下：

- 操作系统：Windows 11；
- 设备：笔记本电脑；
- 外接显示器：无；
- 分辨率：2880 × 1620；
- 缩放比例：200%；
- HDR：已开启；
- 应用主题：浅色主题下最明显；
- 应用：ChatGPT 桌面应用中的 Codex 功能。

## 5. 已尝试的排查步骤

### 5.1 重置图形驱动

使用以下快捷键重置 Windows 图形驱动：

```text
Win + Ctrl + Shift + B
```

执行后屏幕会短暂闪烁。

结果：问题未解决。

### 5.2 检查应用版本

确认 Codex / ChatGPT 桌面应用已经更新到最新版本。

结果：应用版本不是主要原因。

### 5.3 排除外接显示器影响

确认当前没有连接外接显示器，因此可以基本排除多显示器、不同 DPI 或跨屏显示造成的问题。

### 5.4 进入 Windows 图形设置

通过以下方式进入图形设置：

```text
Win + R
```

输入：

```text
ms-settings:display-advancedgraphics
```

进入：

```text
设置 → 系统 → 屏幕 → 显示卡
```

### 5.5 添加 ChatGPT 应用

在“应用程序的自定义设置”中：

1. 点击“添加 Microsoft Store 应用”；
2. 选择 ChatGPT；
3. 将 ChatGPT 添加到图形设置列表。
![[Windows 图形设置页面.png]]

## 6. 最终解决方案

在 ChatGPT 的图形设置中，将“GPU 首选项”从：

```text
让 Windows 决定
```

修改为：

```text
节能
```

然后执行以下操作：

1. 打开任务管理器；
2. 结束所有 ChatGPT、Codex 或 OpenAI 相关进程；
3. 重新启动 ChatGPT 桌面应用；
4. 再次进入 Codex 设置页面；
5. 滚动左侧侧边栏进行验证。

修改后，侧边栏的黑色背景、重绘异常和滚动显示问题消失。

![[ChatGPT GPU 首选项设置为节能.png]]
## 7. 排查结论

本次问题最终通过调整 ChatGPT 的 GPU 首选项解决。

根据结果判断，问题大概率与以下因素有关：

- 应用默认使用的 GPU 渲染路径存在兼容性问题；
- 高性能 GPU 或当前默认 GPU 的驱动在处理应用侧边栏合成时发生异常；
- 将应用切换到“节能”模式后，Windows 改用另一套 GPU 渲染路径，从而恢复正常显示。

因此，这次故障更接近软件渲染、显卡驱动或 GPU 合成问题，而不是显示器硬件故障。

## 8. 后续建议

如果问题再次出现，可以依次尝试：

1. 彻底退出并重新启动 ChatGPT；
2. 确认 GPU 首选项仍为“节能”；
3. 更新核显和独显驱动；
4. 测试关闭 HDR；
5. 测试关闭“窗口化游戏优化”；
6. 临时调整 Windows 缩放比例；
7. 在 Windows 应用设置中修复或重置 ChatGPT；
8. 卸载并重新安装 ChatGPT 桌面应用。
