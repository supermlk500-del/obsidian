PyCharm 提供了非常丰富的快捷键，以下是主要的快捷键分类整理：

## 🎯 编辑相关快捷键

### 基础编辑
- `Ctrl + Space` - 基本代码补全
- `Ctrl + Shift + Space` - 智能类型补全
- `Ctrl + P` - 参数信息
- `Ctrl + Q` - 快速文档查看
- `Ctrl + /` - 行注释/取消注释
- `Ctrl + Shift + /` - 块注释
- `Ctrl + W` - 逐步选择代码块
- `Ctrl + Shift + W` - 逐步取消选择
- `Tab` / `Shift + Tab` - 缩进/取消缩进

### 代码生成
- `Alt + Insert` - 生成代码（构造函数、getter/setter等）
- `Ctrl + O` - 重写方法
- `Ctrl + I` - 实现方法
- `Ctrl + Alt + T` - 环绕代码（if, try-catch等）

## 🔍 导航相关快捷键

### 文件导航
- `Ctrl + N` - 跳转到类
- `Ctrl + Shift + N` - 跳转到文件
- `Ctrl + Alt + Shift + N` - 跳转到符号
- `Alt + Left/Right` - 切换编辑标签页
- `F12` - 返回上次工具窗口

### 代码导航
- `Ctrl + B` / `Ctrl + Click` - 跳转到声明
- `Ctrl + Alt + B` - 跳转到实现
- `Ctrl + Shift + I` - 快速定义查看
- `Ctrl + U` - 跳转到父类/方法
- `Alt + F7` - 查找用法
- `Ctrl + F7` - 在文件中查找用法

## 🔎 搜索替换

- `Ctrl + F` - 查找
- `F3` / `Shift + F3` - 查找下一个/上一个
- `Ctrl + R` - 替换
- `Ctrl + Shift + F` - 在路径中查找
- `Ctrl + Shift + R` - 在路径中替换
- `Ctrl + Shift + F` - 全局查找

## 🛠️ 重构相关

- `F5` - 复制
- `F6` - 移动
- `Shift + F6` - 重命名
- `Ctrl + F6` - 更改签名
- `Ctrl + Alt + M` - 提取方法
- `Ctrl + Alt + V` - 提取变量
- `Ctrl + Alt + F` - 提取字段
- `Ctrl + Alt + C` - 提取常量
- `Ctrl + Alt + P` - 提取参数

## 🎮 运行调试

- `Shift + F10` - 运行
- `Shift + F9` - 调试
- `Ctrl + F2` - 停止
- `F9` - 恢复程序
- `F8` - 步过
- `F7` - 步入
- `Shift + F8` - 步出
- `Alt + F9` - 运行到光标
- `Alt + F8` - 计算表达式

## 📁 项目相关

- `Alt + 1` - 显示/隐藏项目窗口
- `Ctrl + Alt + Shift + S` - 项目结构
- `Ctrl + Shift + F12` - 最大化编辑器
- `Ctrl + E` - 最近文件
- `Ctrl + Shift + E` - 最近编辑的文件

## 🎨 视图相关

- `Ctrl + ~` - 快速切换主题/配色方案
- `Ctrl + F12` - 文件结构弹出
- `Ctrl + H` - 类型层次结构
- `Ctrl + Shift + H` - 方法层次结构
- `F4` - 查看源代码

## 💡 实用功能

- `Alt + Enter` - 显示意图动作和快速修复
- `Ctrl + Alt + L` - 格式化代码
- `Ctrl + Alt + O` - 优化导入
- `Ctrl + Shift + A` - 查找动作
- `Double Shift` - 搜索所有内容
- `Ctrl + Shift + F8` - 查看断点

## 🖱️ 多光标编辑

- `Alt + Click` - 添加/删除光标
- `Ctrl + Alt + Shift + Click` - 添加矩形选择
- `Alt + Drag` - 列选择模式
- `Ctrl + Shift + Alt + J` - 选择所有出现的内容

## 🔧 版本控制

- `Ctrl + K` - 提交更改
- `Ctrl + T` - 更新项目
- `Alt + Shift + C` - 查看最近更改
- `Ctrl + Alt + Z` - 回滚更改

## 💡 使用技巧

1. **自定义快捷键**：File → Settings → Keymap
2. **快捷键冲突检查**：在Keymap设置中查看冲突
3. **学习模式**：使用`Ctrl + Shift + A`搜索不熟悉的快捷键
4. **插件增强**：安装Key Promoter X插件学习快捷键

这些快捷键可以显著提高开发效率，建议先从最常用的开始掌握！
