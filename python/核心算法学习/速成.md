这段代码展示了 Python 中一个非常强大且极其常用的内置工具：`collections` 模块下的 **`Counter`** 类。顾名思义，它的核心功能就是**“计数”**。

在解释代码前，先指出一个小细节：你提供的第一行代码把导入语句和变量赋值连在一起了，正确的格式应该是分行的：

Python

```
from collections import Counter
list1 = ["a", "a", "a", "b", "c", "c", "f", "g", "g", "g", "f"]
```

下面我们将代码拆解为两个核心部分来解释：

### 1. 基本的频次统计

Python

```
dic = Counter(list1)
print(dic)
# Counter({'a': 3, 'g': 3, 'c': 2, 'f': 2, 'b': 1})
```

- **运行逻辑：** 当你把一个列表（或者字符串等可迭代对象）传给 `Counter()` 时，它会在底层自动遍历这个列表，并统计每一个元素出现的总次数。
    
- **返回值：** 它返回一个类似于字典（`dict`）的对象。在这个字典中，**键（Key）是列表中的元素，值（Value）是该元素出现的次数**。并且，它默认会按照出现次数从高到低为你排好序。
    

### 2. 提取出现次数最多的元素 `most_common()`

Python

```
list1 = ["a", "a", "a", "b", "c", "f", "g", "g", "c", "11", "g", "f", "10", "2"]

# 提取前 3 名
print(Counter(list1).most_common(3))
# 结果：[('a', 3), ('g', 3), ('c', 2)]

# 提取第 1 名
print(Counter(list1).most_common(1))
# 结果：[('a', 3)]
```

- **运行逻辑：** `most_common(n)` 是 `Counter` 最实用的方法。传入参数 `n`，它就会帮你返回出现次数排名前 `n` 的元素。如果不传参数（即 `most_common()`），它会返回所有元素按频次排好序的列表。
    
- **重点注意返回格式：** 它的返回值**不是字典**，而是一个**列表**。列表里面的每一个元素是一个**元组** `(元素, 频次)`。
    
    - 如果你要在后续代码中获取排名第一的字符，你需要通过索引提取：`Counter(list1).most_common(1)[0][0]` （第一个 `[0]` 取出元组 `('a', 3)`，第二个 `[0]` 取出字符 `'a'`）。
        

---

### 💡 竞赛实战意义

在蓝桥杯这类算法竞赛中，`Counter` 是一个绝对的“神级”工具。

如果你不用 `Counter`，想找出列表中出现次数最多的元素，你需要手写这样的代码：

Python

```
# 传统写法：自己建字典统计，自己写排序逻辑
counts = {}
for item in list1:
    counts[item] = counts.get(item, 0) + 1
# 还要再写一行复杂的 lambda 排序来找出最大值...
```

而使用 `Counter`，复杂的统计加排序逻辑**只需一行代码**即可秒杀。在遇到“求众数”、“词频统计”、“判断两个字符串是否由相同字符组成（字母异位词）”等考点时，熟练运用 `Counter` 可以为你节省大量比赛时间并大幅降低代码出错率。

## 蓝桥杯常用库速查（建议背下来）

```python
from collections import deque, defaultdict, Counter
import heapq
import bisect

# 双端队列
q = deque([1, 2, 3])
q.appendleft(0)
q.append(4)
q.popleft()
q.pop()

# defaultdict
cnt = defaultdict(int)
cnt['a'] += 1

# 二分库（有序数组）
nums = [1, 2, 2, 4]
pos1 = bisect.bisect_left(nums, 2)   # 1
pos2 = bisect.bisect_right(nums, 2)  # 3

# 堆（最小堆）
h = []
heapq.heappush(h, 3)
heapq.heappush(h, 1)
top = heapq.heappop(h)  # 1
```
