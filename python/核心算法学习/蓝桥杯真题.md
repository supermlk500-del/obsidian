# 蓝桥杯真题

## 题目1：统计区间内“完全不包含 2023”的数字个数

### 题目描述

请统计在区间 `[12345678, 98765432]` 中，有多少个数**完全不包含 `2023`**。

这里“包含 `2023`”指的是：可以从这个数中按顺序选出若干位，得到 `2 -> 0 -> 2 -> 3`。

- 注意：不要求连续，是**子序列**，不是子串。
- 例如：
  - `20230415` 包含 `2023`
  - `20193213` 也包含 `2023`（取第 1,2,6,8 位）

---

### 思路分析

#### 1) 先澄清判定方式：子序列，不是子串

很多同学会写 `"2023" in str(x)`，这是判断**连续子串**，本题会错。

正确判定是用一个指针 `j` 去匹配目标串 `"2023"`：

- 从左到右扫描当前数字的每一位
- 遇到和 `target[j]` 相同的字符，就 `j += 1`
- 如果 `j == 4`，说明已经匹配出 `2023`

#### 2) 为什么不能直接暴力遍历整个区间

区间长度约是 `8.6e7`（8600多万个数），逐个判断在 Python 中通常会超时。

#### 3) 正确做法：数位 DP

我们不逐个枚举数字，而是按位构造并计数。

定义 `dfs(i, matched, tight, started)`：

- `i`：处理到第几位
- `matched`：当前已经匹配了 `"2023"` 前几位（0~4）
- `tight`：前缀是否和上界一致（决定本位上限）
- `started`：是否已经放过非前导零（避免前导零干扰匹配）

转移时枚举当前位 `d`，更新状态。

- 一旦 `matched == 4`，说明出现了 `2023`，该分支非法，返回 `0`
- 处理完所有位且未匹配满，返回 `1`

最后用前缀计数：

`answer = count_not_contain(R) - count_not_contain(L - 1)`

---

### 参考代码（Python）

```python
from functools import lru_cache

PAT = "2023"


def count_not_contain(x: int) -> int:
    """
    统计 [0, x] 中“完全不包含 2023(子序列)”的数的个数
    """
    if x < 0:
        return 0

    s = str(x)
    n = len(s)

    @lru_cache(None)
    def dfs(i: int, matched: int, tight: int, started: int) -> int:
        # 已匹配出 2023，非法
        if matched == 4:
            return 0

        # 所有位处理完，且没匹配满 2023，合法
        if i == n:
            return 1

        up = int(s[i]) if tight else 9
        ans = 0

        for d in range(up + 1):
            ntight = 1 if (tight and d == up) else 0
            nstarted = 1 if (started or d != 0) else 0

            nmatched = matched
            if nstarted and matched < 4 and str(d) == PAT[matched]:
                nmatched += 1

            ans += dfs(i + 1, nmatched, ntight, nstarted)

        return ans

    return dfs(0, 0, 1, 0)


L = 12345678
R = 98765432
print(count_not_contain(R) - count_not_contain(L - 1))
```

---

### 本题答案

`85959030`

---

### 易错点总结

1. 把“子序列”误写成“子串”。
2. 前导零参与匹配，导致统计错误（`started` 状态要处理）。
3. 只算 `count_not_contain(R)`，忘记减去 `count_not_contain(L-1)`。

## 题目2：硬币兑换后同面值数量最大化

### 题目描述

有 `2023` 种新版硬币：

- 第 `i` 种硬币面值为 `i`
- 数量也为 `i` 枚（`1 <= i <= 2023`）

兑换机规则：每次投入两枚**新版**硬币 `coin1`、`coin2`，会得到一枚面值 `coin1 + coin2` 的**旧版**硬币。

可以兑换任意次。最终只看面值，不看新旧。设每种面值的数量为 `sum_i`，目标是最大化：

`max(sum_1, sum_2, ..., sum_k)`。

---

### 思路分析

#### 1) 固定目标面值 `v`

如果我们想让“面值 `v` 的硬币数量最多”，那只需要做两类贡献：

- 原来就有的新版 `v`（若 `v <= 2023`，有 `v` 枚）
- 通过兑换得到的旧版 `v`

#### 2) 兑换成 `v` 的方式是配对 `(a, v-a)`

对于每个 `a`，它只能和 `v-a` 配成 `v`，所以是独立配对。

- 若 `a != v-a`，最多可兑换 `min(cnt[a], cnt[v-a])` 次
- 若 `a == v-a`（即 `v` 为偶数中点），最多 `cnt[a] // 2` 次

这里 `cnt[i] = i`。

因此固定 `v` 时：

`total(v) = (v if 1<=v<=2023 else 0) + 可兑换出的 v 的总次数`

我们把 `v` 从 `1` 枚举到 `4046`（最大和），取最大值即可。

#### 3) 复杂度

外层枚举 `v`，内层枚举 `a`，复杂度 `O(2023^2)`，完全可跑。

---

### 参考代码（Python）

```python
N = 2023
cnt = [0] + [i for i in range(1, N + 1)]


def make_count(v: int) -> int:
    # 原有同面值新版硬币
    total = cnt[v] if 1 <= v <= N else 0

    # 用新版硬币配对兑换出面值 v 的旧版硬币
    for a in range(1, N + 1):
        b = v - a
        if not (1 <= b <= N):
            continue
        if a < b:
            total += min(cnt[a], cnt[b])
        elif a == b:
            total += cnt[a] // 2
        # a > b 时跳过，避免重复计算

    return total


ans = 0
for v in range(1, 2 * N + 1):
    ans = max(ans, make_count(v))

print(ans)
```

---

### 本题答案

`682425`

---

### 易错点总结

1. 误以为旧版硬币还能继续兑换（不行，机器只吃新版）。
2. 忘记 `a == b` 时是 `cnt[a] // 2`。
3. 计算配对时把 `(a,b)` 和 `(b,a)` 重复统计。

## 题目3：松散子序列的最大价值

### 题目描述

给定仅包含小写字母的字符串 `s`。

定义一个子序列 `t` 为“松散子序列”，当且仅当它在原串中相邻选中位置满足：

- 对任意 `i > 1`，有 `p_i - p_{i-1} >= 2`

也就是：不能选相邻位置的字符。

每个字符有价值：`a~z` 对应 `1~26`。

求松散子序列的最大总价值。

---

### 思路分析

这是经典线性 DP（和“打家劫舍”同型）：

- 每个位置 `i` 只有两种选择：
  1. 不选第 `i` 位 -> 价值 `dp[i-1]`
  2. 选第 `i` 位 -> 价值 `dp[i-2] + val[i]`

因此转移：

`dp[i] = max(dp[i-1], dp[i-2] + val[i])`

其中：

- `val[i] = ord(s[i-1]) - ord('a') + 1`（1-based DP）
- `dp[0] = 0`
- `dp[1] = val[1]`

最终答案是 `dp[n]`。

#### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`（可优化到 `O(1)`）

---

### 参考代码（Python）

```python
import sys

input = lambda: sys.stdin.readline().strip()

s = input()
n = len(s)

if n == 0:
    print(0)
    raise SystemExit

val = [0] * (n + 1)
for i in range(1, n + 1):
    val[i] = ord(s[i - 1]) - ord('a') + 1

dp = [0] * (n + 1)
dp[1] = val[1]

for i in range(2, n + 1):
    dp[i] = max(dp[i - 1], dp[i - 2] + val[i])

print(dp[n])
```

---

### 样例解释

输入：`azaazaz`

字符价值：`1, 26, 1, 1, 26, 1, 26`

最优选择可以是第 `2, 5, 7` 位：`26 + 26 + 26 = 78`。

因此输出：`78`。

---

### 易错点总结

1. 把题目理解成“不能有相同字母”，实际上是“不能选相邻位置”。
2. 下标混用（字符串 0-based，DP 常用 1-based）。
3. 忘记处理空串或长度为 1 的边界。

## 题目4：管道各段最早检测到水流时间

### 题目描述

管道长度为 `len`，分成 `1..len` 段。第 `i` 个阀门位于 `L_i`，在时刻 `S_i` 打开并持续放水。

水速为每单位时间扩散 1 段，因此在时刻 `T`，该阀门影响范围是：

`[L_i - (T - S_i), L_i + (T - S_i)]`。

要求输出每一段传感器最早检测到水流的时间。

---

### 思路分析

对任意位置 `x`，由阀门 `i` 传到 `x` 的最早时间是：

`S_i + |x - L_i|`

所以答案是：

`ans[x] = min_i (S_i + |x - L_i|)`

这不是二分题，更像“线性距离最小值”问题。

做法：

1. 先建数组 `base[p]`：位置 `p` 上阀门的最早开启时间（同一位置多个阀门取最小）
2. 左到右扫：`left[x] = min(base[x], left[x-1] + 1)`
3. 右到左扫：`ans[x] = min(left[x], ans[x+1] + 1)`

时间复杂度 `O(n + len)`，空间 `O(len)`。

---

### 参考代码（Python）

```python
import sys

input = lambda: sys.stdin.readline().strip()

n, length = map(int, input().split())
INF = 10**18

base = [INF] * (length + 1)  # 1..length

for _ in range(n):
    L, S = map(int, input().split())
    if S < base[L]:
        base[L] = S

# 左到右
left = [INF] * (length + 1)
for x in range(1, length + 1):
    left[x] = base[x]
    if x > 1:
        left[x] = min(left[x], left[x - 1] + 1)

# 右到左
ans = [INF] * (length + 1)
for x in range(length, 0, -1):
    ans[x] = left[x]
    if x < length:
        ans[x] = min(ans[x], ans[x + 1] + 1)

print(*ans[1:])
```

---

### 易错点总结

1. 误判成二分题，实际上是 `min(S_i + |x-L_i|)` 的线性扫描题。
2. 同一 `L_i` 可能有多个阀门，`base[L_i]` 要取最小 `S_i`。
3. 只做一遍扫描会漏掉另一侧阀门影响，必须左右各一遍。

## 题目5：保险箱数字最少操作次数

### 题目描述

有一个 `n` 位数字保险箱，初始为字符串 `x`，目标为 `y`。

一次操作可以选择某一位加 `1` 或减 `1`。当某位从 `9` 加 `1` 或从 `0` 减 `1` 时，会向左进位/退位；最高位再向左的进退位忽略。

求把 `x` 变成 `y` 的最少操作次数。

---

### 思路分析

这题不是二分题，而是**按位 DP（带进位状态）**。

从最低位到最高位处理，设当前位置（从右往左）有一个来自右侧的进位/退位 `carry`，
我们决定本位做多少次净操作 `t`（加操作次数减去减操作次数），使本位匹配目标并产生新的 `next_carry`。

有方程：

`x_i + carry + t = y_i + 10 * next_carry`

所以：

`t = y_i - (x_i + carry) + 10 * next_carry`

本位代价是 `|t|`，总目标是最小化总代价。

#### 为什么 `carry` 只需要考虑 `-1, 0, 1`

在十进制下，最优解不会需要更大的进位绝对值；超过 1 的进位会带来额外 10 的代价，不会优于就近调整。

因此 DP 状态只有 3 个，复杂度是 `O(9n)`，即 `O(n)`。

---

### 参考代码（Python）

```python
import sys

input = lambda: sys.stdin.readline().strip()

n = int(input())
x = input().strip()
y = input().strip()

# 保险：如果输入没有补足前导零，可按 n 位左补零
x = x.zfill(n)
y = y.zfill(n)

INF = 10**18
state = [-1, 0, 1]
idx = {-1: 0, 0: 1, 1: 2}

# dp[c]：处理到当前更低位后，传给本位的 carry=c 的最小代价
dp = [INF, 0, INF]  # 初始 carry=0

for pos in range(n - 1, -1, -1):
    xi = ord(x[pos]) - ord('0')
    yi = ord(y[pos]) - ord('0')
    ndp = [INF, INF, INF]

    for c in state:
        cur = dp[idx[c]]
        if cur >= INF:
            continue

        for nc in state:
            t = yi - (xi + c) + 10 * nc
            cost = abs(t)
            j = idx[nc]
            if cur + cost < ndp[j]:
                ndp[j] = cur + cost

    dp = ndp

# 最高位再往左的进退位忽略 => 最后 carry 不受限制
print(min(dp))
```

---

### 易错点总结

1. 误用二分：本题没有单调性，不是二分答案。
2. 忘记“最高位外溢忽略”，导致错误地强制最终 carry=0。
3. 把 `x,y` 当整数读入，丢失前导零；应按字符串处理。
