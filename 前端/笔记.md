## 盒子模型
- 盒子：页面中所有的元素，都可以看做是一个盒子，由盒子将页面中的元素包含在一个矩形区域内，通过盒子的视角更方便的进行布局
- 盒子模型的组成：内容区域(content)、内边距区域(padding)、边框区域(border)、外边距区域(margin)。比如手机盒子，手机是内容区域，手机到盒子边框的距离是内边距区域，盒子边框的宽度是边框区域，盒子里其他物体的距离叫外边距区域。
### 布局标签
- 网页开发中，会使用 div 和 span 这两个没有语义的布局标签
-  div 标签：一行只显示一个 宽度默认是父元素的宽度，高度默认由内容撑开可以设置宽高
- span 标签：一行可以显示多个，宽度和高度默认由内容撑开，不可以设置宽高
## flex布局
- flex是flesible的缩写，意为“弹性布局”，是一种一维的布局模型。flex布局可以为元素之间提供强大的空间分布和对齐能力
- 通过给父容器添加flex的相关属性，来控制子元素的位置和排列方式
好的，这里将 Flex 布局中作用于**容器**和**项目**的所有属性及其取值含义整理成表格，方便您查阅。

#### Flex 容器属性

这些属性定义在 Flex 容器（设置了 `display: flex` 的元素）上，用于控制其内部项目的整体布局流。

| 属性                    | 含义                                     | 常用取值                           | 取值含义                          |
| :-------------------- | :------------------------------------- | :----------------------------- | :---------------------------- |
| **`display`**         | 定义 Flex 容器                             | `flex`                         | 块级 Flex 容器                    |
|                       |                                        | `inline-flex`                  | 行内 Flex 容器                    |
| **`flex-direction`**  | 定义主轴方向（项目的排列方向）                        | `row` (默认值)                    | 主轴为水平方向，起点在左端                 |
|                       |                                        | `row-reverse`                  | 主轴为水平方向，起点在右端                 |
|                       |                                        | `column`                       | 主轴为垂直方向，起点在上沿                 |
|                       |                                        | `column-reverse`               | 主轴为垂直方向，起点在下沿                 |
| **`flex-wrap`**       | 定义项目是否换行                               | `nowrap` (默认值)                 | 不换行，所有项目挤在一行                  |
|                       |                                        | `wrap`                         | 换行，第一行在上方                     |
|                       |                                        | `wrap-reverse`                 | 换行，第一行在下方                     |
| **`flex-flow`**       | `flex-direction` 和 `flex-wrap` 的简写     | `<flex-direction> <flex-wrap>` | 例如：`flex-flow: row wrap;`     |
| **`justify-content`** | 定义项目在**主轴**上的对齐方式                      | `flex-start` (默认值)             | 与主轴起点对齐                       |
|                       |                                        | `flex-end`                     | 与主轴终点对齐                       |
|                       |                                        | `center`                       | 居中                            |
|                       |                                        | `space-between`                | 两端对齐，项目之间间隔相等                 |
|                       |                                        | `space-around`                 | 每个项目两侧的间隔相等（项目之间的间隔是项目与边框的2倍） |
|                       |                                        | `space-evenly`                 | 每个项目的间隔与项目离边框的间隔都相等           |
| **`align-items`**     | 定义项目在**交叉轴**上的对齐方式（单行）                 | `stretch` (默认值)                | 如果项目未设置高度或设为 auto，将占满整个容器的高度  |
|                       |                                        | `flex-start`                   | 与交叉轴的起点对齐                     |
|                       |                                        | `flex-end`                     | 与交叉轴的终点对齐                     |
|                       |                                        | `center`                       | 在交叉轴中居中                       |
|                       |                                        | `baseline`                     | 与项目的第一行文字的基线对齐                |
| **`align-content`**   | 定义**多根轴线**（多行）在**交叉轴**上的对齐方式（单行时此属性无效） | `stretch` (默认值)                | 轴线占满整个交叉轴                     |
|                       |                                        | `flex-start`                   | 与交叉轴的起点对齐                     |
|                       |                                        | `flex-end`                     | 与交叉轴的终点对齐                     |
|                       |                                        | `center`                       | 与交叉轴的中点对齐                     |
|                       |                                        | `space-between`                | 与交叉轴两端对齐，轴线之间间隔平均分布           |
|                       |                                        | `space-around`                 | 每根轴线两侧的间隔都相等                  |
|                       |                                        | `space-evenly`                 | 每根轴线的间隔与轴线离边框的间隔都相等           |

#### Flex 项目属性

这些属性定义在 Flex 容器内的直接子元素（Flex 项目）上。

| 属性 | 含义 | 常用取值 | 取值含义 |
| :--- | :--- | :--- | :--- |
| **`order`** | 定义项目的排列顺序 | `<integer>` (整数，默认 0) | 数值越小，排列越靠前 |
| **`flex-grow`** | 定义项目的放大比例 | `<number>` (数字，默认 0) | 如果存在剩余空间，也不放大 |
| | | `1` (或更大) | 如果所有项目的 `flex-grow` 都为 1，它们将等分剩余空间。某个项目为 2，它将占据的剩余空间是其他项目的 2 倍 |
| **`flex-shrink`** | 定义项目的缩小比例 | `<number>` (数字，默认 1) | 如果空间不足，该项目将缩小 |
| | | `0` | 即使空间不足，该项目也不缩小 |
| **`flex-basis`** | 定义在分配多余空间之前，项目占据的主轴空间 | `auto` (默认值) | 项目本来的大小 |
| | | `<length>` (如 200px, 20%) | 设置固定的长度或百分比 |
| | | `content` | 基于项目的内容自动计算大小 |
| **`flex`** | `flex-grow`, `flex-shrink` 和 `flex-basis` 的简写 | `none` | 等价于 `0 0 auto` (不放大也不缩小，尺寸为自身大小) |
| | | `auto` | 等价于 `1 1 auto` (可放大可缩小，尺寸为自身大小) |
| | | `1` (一个无单位数) | 等价于 `1 1 0%` (可放大可缩小，基准为0，按比例分配空间) |
| | | `<grow> <shrink> <basis>` | 例如：`flex: 0 1 200px;` |
| **`align-self`** | 允许单个项目有与其他项目不一样的对齐方式，可覆盖 `align-items` | `auto` (默认值) | 继承父容器的 `align-items` 属性 |
| | | `stretch` | 拉伸以填满容器交叉轴 |
| | | `flex-start` | 与交叉轴的起点对齐 |
| | | `flex-end` | 与交叉轴的终点对齐 |
| | | `center` | 在交叉轴中居中 |
| | | `baseline` | 与项目的第一行文字的基线对齐 |

#### 总结与记忆技巧

*   **主轴与交叉轴**：理解 Flex 布局的关键。`flex-direction` 定义了主轴方向，交叉轴则与之垂直。
*   **起止点**：`-start` 和 `-end` 是相对于文字方向（如 LTR 或 RTL）的。
*   **容器属性管整体**：控制所有项目的排列、对齐和换行。
*   **项目属性管个体**：控制单个项目的顺序、伸缩性和独立对齐。

## 表单标签
- 表单：在网页中主要负责数据采集功能，如注册、登录
- 标签：form
- 表单项
```html
<input>:定义表单项，通过type属性控制器输入形式（text/password）
<select>:定义下拉列表
<textarea>:定义文本域
```
- 属性：
```text
action:规定当提交表单时向何处发送表单数据,url
method:规定用于发送表单数据的方式。
	GET：默认，表单数据会出现在url后面。形式/save?name=Tom&age=18
		特点：
			1.如果表单中包含了隐私数据，get方式并不安全，不推荐使用该方式
			2.在浏览器中get请求得大小是有限制得，大概在2kb，不适合提交大数据量得表单
			3.速度快
			4.查询，删除
	POST：表单数据会在消息体/请求体中提交到服务器
		特点：
			1.更加安全
			2.请求大小没有限制
			3.速度慢
			4.修改，插入，注册，登录
```
- 表单项要想能够采集数据，必须得设置name属性，表示当前表单项得名字
```html
<form avtion="/save" method="get">
	name:<input type="text" name="name"> 
	age:<input type="text" name="age"> 
	<input type="submit" value="提交">
<form>
```

## JavaScript
- 负责网页的行为（交互效果）
### 语法
#### 引入
- 内部脚本：将JS代码定义在HTML页面中
1. javascript代码必须位于<script></script>标签中
2. 在HTML文档中，可以在任意地方，放置任意数量的(<script)
3. 一般会把脚本置于<body元素的底部，可改善显示速度。
- 外部脚本：将JS代码定义在外部 JS文件中，然后引入到HTML页面中
#### 变量和常量
- JS中用 let 关键字来声明变量（弱类型语言，变量可以存放在不同类型的值）
- 变量名需要遵循如下规则
1. 只能用字母，数字。下划线，美元符号组成，且数字不能开头
2. 变量名严格区分大小写
3. 不能使用关键字
```javascript
<script>
	//变量
	let a = 20;
	a = "Hello";
	//弹出框
	alert(a);//不会报错，因为javascript是弱语言类型。输出为Hello
</script>
```

```javascript
//常量
<script>
	//常量
	const PI = 3.14;
	PI = 3;//注意这里会报错
	//输出在控制台
	console.log(PI);
	document.write(PI);//直接把值写入<body>区域
</script>
```

#### 数据类型
- 基本数据类型
1. number：数字（整数，小数，Nan（Not a Number））
2. boolean：布尔
3. null：对象为空。注意大小写敏感
4. underfined：当声明的对象未初始化时，该变量的默认值时undefined
5. string：字符串，单引号，双引号，反引号都可
	- 使用 typeof 运算符可以获取数据类型
- 模板字符串：注意变量需要用反引号
	- 内容拼接变量时，使用 ${} 包住变量
#### 函数
- 介绍：被设计用来执行特定任务的代码块，方便程序的封装复用
##### 匿名函数是指一种没有名称的函数
- 可以通过两种方式定义：函数表达式和箭头函数
```javascript
let add = function(a,b){
	return a + b;
}//函数表达式
let add = (a,b) =>{
	return a + b;
}//箭头函数
```
