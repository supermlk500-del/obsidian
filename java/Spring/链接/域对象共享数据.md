# ✅ 13.8 域对象共享数据（完整版笔记）

## 一、request域共享数据（5种方式）

---

## 1️⃣ 使用 Servlet API（HttpServletRequest）

### ✅ 用法

```java
@RequestMapping("/testRequest")
public String testRequest(HttpServletRequest request){
    request.setAttribute("msg","hello request");
    return "success";
}
```

### 📌 前端获取

```html
${msg}
```

### 🧠 原理

- 本质：调用 `request.setAttribute()`
    
- 数据存储在 request 域中
    

### ⚠️ 注意

- 依赖 Servlet API（**耦合高，不推荐在SpringMVC中大量使用**）
    

---

## 2️⃣ 使用 ModelAndView

### ✅ 用法

```java
@RequestMapping("/testModelAndView")
public ModelAndView testModelAndView(){
    ModelAndView mav = new ModelAndView();
    mav.addObject("msg","hello ModelAndView");
    mav.setViewName("success");
    return mav;
}
```

### 🧠 特点

- 同时处理：
    
    - 数据（Model）
        
    - 视图（View）
        

### ⚠️ 注意

- 代码稍微繁琐
    
- 现在开发中使用较少（被 Model 替代）
    

---

## 3️⃣ 使用 Model（⭐⭐⭐⭐⭐ 推荐）

### ✅ 用法

```java
@RequestMapping("/testModel")
public String testModel(Model model){
    model.addAttribute("msg","hello model");
    return "success";
}
```

### 🧠 本质

```java
request.setAttribute()
```

### ⚠️ 注意

- **SpringMVC 最推荐方式**
    

---

## 4️⃣ 使用 Map

### ✅ 用法

```java
@RequestMapping("/testMap")
public String testMap(Map<String,Object> map){
    map.put("msg","hello map");
    return "success";
}
```

### 🧠 本质

- 最终也是 request 域
    

---

## 5️⃣ 使用 ModelMap

### ✅ 用法

```java
@RequestMapping("/testModelMap")
public String testModelMap(ModelMap modelMap){
    modelMap.addAttribute("msg","hello modelMap");
    return "success";
}
```

---

## 6️⃣ Model、ModelMap、Map 关系（🔥面试重点）

### 🧠 关系图

```
          Model (接口)
             ↑
        BindingAwareModelMap
           ↑
     ModelMap (类)
           ↑
          Map
```

### 📌 总结一句话：

👉 **三者本质一样，底层都是 request 域**

### 📌 区别

|类型|本质|推荐|
|---|---|---|
|Model|接口|⭐⭐⭐⭐⭐|
|Map|接口|⭐⭐⭐|
|ModelMap|类|⭐⭐⭐|

### ⚠️ 注意

- Spring 最终会把它们统一为：
    

```java
BindingAwareModelMap
```

# 二、session域共享数据

---

## 7️⃣ 向 Session 域共享数据

### ✅ 方法1：使用 Servlet API

```java
@RequestMapping("/testSession")
public String testSession(HttpSession session){
    session.setAttribute("msg","hello session");
    return "success";
}
```

---

### ✅ 方法2：使用 @SessionAttributes（了解）

```java
@Controller
@SessionAttributes("msg")
public class TestController {

    @RequestMapping("/testSessionAttr")
    public String testSessionAttr(Model model){
        model.addAttribute("msg","hello session");
        return "success";
    }
}
```

### 🧠 原理

- 自动把 Model 中的数据存入 session
    

### ⚠️ 注意（很重要❗）

- 必须写在类上
    
- 只对指定 key 生效
    
- 不推荐大量使用（容易混乱）
    

---

# 三、application域共享数据

---

## 8️⃣ 向 Application 域共享数据（ServletContext）

### ✅ 用法

```java
@RequestMapping("/testApplication")
public String testApplication(HttpSession session){
    ServletContext application = session.getServletContext();
    application.setAttribute("msg","hello application");
    return "success";
}
```

---

## 🧠 三大域总结（超重要）

|域|生命周期|范围|
|---|---|---|
|request|一次请求|当前请求|
|session|一次会话|浏览器|
|application|服务器启动到关闭|全局|

---

# 四、完整案例（面试级）

```java
@Controller
public class ScopeController {

    @RequestMapping("/scope")
    public String testScope(Model model, HttpSession session){
        // request
        model.addAttribute("req","request数据");

        // session
        session.setAttribute("sess","session数据");

        // application
        ServletContext app = session.getServletContext();
        app.setAttribute("app","application数据");

        return "success";
    }
}
```

### 页面获取：

```html
request: ${req}
session: ${sessionScope.sess}
application: ${applicationScope.app}
```

# 五、重点总结（直接背🔥）

### ⭐ request域（最常用）

- Model（推荐）
    
- Map / ModelMap（本质一样）
    
- ModelAndView（了解）
    
- HttpServletRequest（不推荐）
    

---

### ⭐ session域

- HttpSession（常用）
    
- @SessionAttributes（了解）
    

---

### ⭐ application域

- ServletContext（全局共享）

# 六、面试高频问题

### ❓1：Model 和 Map 有什么区别？

👉 本质没有区别，最终都是 request 域

---

### ❓2：为什么推荐 Model？

👉 解耦 + Spring 设计规范

### ❓3：三大域作用范围？

👉

- request：一次请求
    
- session：一次会话
    
- application：整个应用
    

---

### ❓4：什么时候用 session？

👉 登录信息 / 用户状态
