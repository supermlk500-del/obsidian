终止占用 8080 端口的进程（最常用）

这是最直接的方法，找出是哪个程序占用了端口，然后关闭它。

**在 Windows 系统上：**

1. **查找占用端口的进程ID（PID）**
    
    - 按 `Win + R` 键，输入 `cmd` 打开命令提示符。
        
    - 输入以下命令：
        
    
    cmd
    
    netstat -ano | findstr :8080
    
    - 你会看到类似这样的输出：
        
    
    text
    
    TCP    0.0.0.0:8080           0.0.0.0:0              LISTENING       12345
    TCP    [::]:8080              [::]:0                 LISTENING       12345
    
    - 记下最后一行的数字，这就是 **PID（进程ID）**，在这里是 `12345`。
--- 


## 在springboot中
- 创建springboot maven项目上 ， 运行时若出现8080端口被占用。在resource文件下的application.properties文件下 添加如下即可
```java
server.port = 8088;//端口
```
