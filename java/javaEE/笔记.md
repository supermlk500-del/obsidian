##  三、Spring AOP 实现

### 1. 定义切面类（XML 方式）
```java
public class ProductAspect {
    public void adviseBefore(JoinPoint jp) {
        System.out.println(jp.getSignature().getName() + " 前置通知");
    }
}
```

### 2. 配置 AOP（XML）
```xml
<aop:config>
    <aop:aspect ref="productAspect">
        <aop:pointcut id="pointCut" expression="execution(* com.spring.aop.xml.*.*(..))"/>
        <aop:before method="adviseBefore" pointcut-ref="pointCut"/>
    </aop:aspect>
</aop:config>
```

### 3. 注解方式
```java
@Aspect
@Component
public class ProductAspect {
    @Before("execution(* com.spring.aop.annotation.*.*(..))")
```

```java
public class ExceptionHandler1 implements HandlerExceptionResolver {
  @Override
  public ModelAndView resolveException(HttpServletRequest request, 
        HttpServletResponse response, Object handler, Exception exp) {
    ModelAndView mav = new ModelAndView();
    mav.addObject("exp", exp);
    mav.setViewName("defaultExp");
    return mav;
  }
}
```

```java
@ControllerAdvice
public class ExceptionHandler2 {

  }
```

#### 2. 控制器处理上传
```java
@RequestMapping("/upload")
public String fileUpload(@RequestParam("uploadfiles") List<MultipartFile> files, HttpServletRequest request) {
  for (MultipartFile file : files) {
    if (!file.isEmpty()) {
      String path = request.getServletContext().getRealPath("/upload/");
      file.transferTo(new File(path + file.getOriginalFilename()));
    }
  }
  return "fileUpload";
}
```

###  文件下载
```java
@RequestMapping("/download")
public ResponseEntity<byte[]> download(HttpServletRequest request, String fileName) throws IOException {
  String filePath = request.getServletContext().getRealPath("/upload/") + fileName;
  byte[] bytes = FileUtils.readFileToByteArray(new File(filePath));
  HttpHeaders headers = new HttpHeaders();
  headers.setContentDispositionFormData("attachment", URLEncoder.encode(fileName, "UTF-8"));
  headers.setContentType(MediaType.APPLICATION_OCTET_STREAM);
  return new ResponseEntity<>(bytes, headers, HttpStatus.OK);
}
```

# springboot
- springboot是为了让程序员更好的使用spring。主要占用就是帮我们快速搭建庞大的spring项目，尽可能减少一切xml配置，做到开箱即用，让我们专注与业务
- 若出现端口占用则 = [[端口占用]]
#### 优势
1. Spring Boot 会根据项目中引入的依赖（如 JAR 包），自动为你配置 Spring 应用程序。
2. 这些是预定义好的依赖描述符，将常用功能相关的多个依赖打包成一个 `starter`。例如，要开发 Web 项目，只需引入 `spring-boot-starter-web`，它会自动引入 Tomcat、Spring MVC、Jackson 等所有相关依赖，避免了版本冲突和繁琐的依赖管理。
3. 几乎零 XML：传统的 Spring 项目有大量的 XML 配置文件，而 Spring Boot 推崇基于 Java 的配置和自动配置，使得 XML 配置成为历史。
4. 由于构建在 Spring 框架之上，Spring Boot 天然继承了 Spring 生态系统的所有优点，并能轻松集成各种主流技术。
5. 由于构建在 Spring 框架之上，Spring Boot 天然继承了 Spring 生态系统的所有优点，并能轻松集成各种主流技术。

| 特性        | 传统 Spring MVC 项目              | Spring Boot 项目                           |
| :-------- | :---------------------------- | :--------------------------------------- |
| **项目搭建**  | 繁琐，需要手动配置大量 XML 或 Java Config | 通过 Spring Initializr 网站一键生成，秒级搭建         |
| **依赖管理**  | 手动添加每个依赖，需自行解决版本冲突            | 使用 Starter，一键引入功能模块                      |
| **内嵌服务器** | 需要将 WAR 包部署到外部 Tomcat         | 内嵌 Tomcat，可直接 `java -jar` 运行             |
| **配置**    | 大量 XML 和注解配置                  | 几乎零配置，`application.properties/yml` 搞定大部分 |
| **部署**    | 需要安装和配置 Web 服务器               | 独立 JAR 包，非常适合云和容器环境                      |
