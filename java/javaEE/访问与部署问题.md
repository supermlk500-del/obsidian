## 🚀 部署过程记录

### 1. 初始问题：应用未部署

#### 问题现象
- Tomcat启动正常，但日志中无stuSystem应用部署记录
- 只有默认应用被部署：
  ```
  把web 应用程序部署到目录 [webapps\docs]
  把web 应用程序部署到目录 [webapps\examples]
  ...
  ```

#### 解决方案
**手动部署应用**：
1. 导出WAR文件：项目右键 → Export → WAR file
2. 复制到Tomcat的webapps目录
3. 重启Tomcat自动解压部署

### 2. Spring配置问题

#### 问题现象
```
BeanDefinitionStoreException: 
Could not open ServletContext resource [/WEB-INF/student.xml]
```

#### 解决方案
创建 `WEB-INF/student.xml` Spring配置文件：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xmlns:mvc="http://www.springframework.org/schema/mvc"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd
                           http://www.springframework.org/schema/context
                           http://www.springframework.org/schema/context/spring-context.xsd
                           http://www.springframework.org/schema/mvc
                           http://www.springframework.org/schema/mvc/spring-mvc.xsd">
    
    <!-- 关键配置 -->
    <context:component-scan base-package="com.springmvc.student" />
    <mvc:annotation-driven />
    
    <!-- 视图解析器 -->
    <bean class="org.springframework.web.servlet.view.InternalResourceViewResolver">
        <property name="prefix" value="/WEB-INF/" />
        <property name="suffix" value=".jsp" />
    </bean>
</beans>
```

### 3. URL访问与安全机制

#### 🔒 重要安全特性
**`/WEB-INF/` 目录保护机制**：
- ❌ 不能直接访问：`http://localhost:8080/stuSystem/WEB-INF/studentpages/login.jsp`
- ✅ 必须通过Controller：`http://localhost:8080/stuSystem/user/login`

#### Controller配置演进

**初始问题代码**：
```java
@Controller
@RequestMapping("/user")
public class UserController {
    @RequestMapping("/login")
    public String showLoginPage() {
        return "studentpages/login";
    }
    
    @RequestMapping("/student/main")  // ❌ 路径不一致
    public String showMainPage() {
        return "studentpages/main";
    }
}
```

**修正后代码**：
```java
@Controller
@RequestMapping("/user")
public class UserController {
    @RequestMapping("/login")
    public String showLoginPage() {
        return "studentpages/login";
    }
    
    @RequestMapping("/main")  // ✅ 统一路径层级
    public String showMain() {
        return "studentpages/main";
    }
}
```

### 4. 表单提交与数据绑定问题

#### 问题1: NullPointerException
```
Cannot invoke "String.equals(Object)" because the return value of "getUsername()" is null
```

**原因**: Spring无法自动绑定表单数据

**解决方案**：
```java
// 添加@ModelAttribute注解
@RequestMapping(value="/loginCheck", method = RequestMethod.POST)
public String logincheck(@ModelAttribute User user, HttpServletRequest request) {
    // 添加空值检查
    if (user.getUsername() == null) {
        return "redirect:/user/login";
    }
    // ... 业务逻辑
}
```

#### 问题2: HTTP方法不支持
```
Request method 'GET' not supported
```

**解决方案**：
1. 检查JSP表单：`<form action="loginCheck" method="post">`
2. 或修改Controller支持双方法：
```java
@RequestMapping(value="/loginCheck", method = {RequestMethod.GET, RequestMethod.POST})
```

### 5. 完整Controller代码

```java
package com.springmvc.student;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpSession;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestMethod;
import org.springframework.web.bind.annotation.ModelAttribute;

@Controller
@RequestMapping("/user")
public class UserController {
    
    @RequestMapping("/login")
    public String showLoginPage() {
        return "studentpages/login";
    }
    
    @RequestMapping("/main")
    public String showMain() {
        return "studentpages/main";
    }
    
    @RequestMapping(value="/loginCheck", method = RequestMethod.POST)
    public String logincheck(@ModelAttribute User user, HttpServletRequest request) {
        // 空值检查
        if (user.getUsername() == null || user.getPassword() == null || user.getRole() == null) {
            HttpSession session = request.getSession();
            session.setAttribute("msg", "请填写完整的登录信息");
            return "redirect:/user/login";
        }
        
        // 测试用户数据
        User admin = new User();
        admin.setUsername("202367021092");
        admin.setPassword("123456");
        admin.setRole("刘辉荣");
        
        // 验证逻辑
        if(admin.getUsername().equals(user.getUsername()) &&
           admin.getPassword().equals(user.getPassword()) &&
           admin.getRole().equals(user.getRole())) {
            
            HttpSession session = request.getSession();
            session.setAttribute("user", user);
            session.setAttribute("msg", "登陆成功");
            return "redirect:/user/main";
        } else {
            HttpSession session = request.getSession();
            session.setAttribute("msg", "用户信息错误");
            return "redirect:/user/login";
        }
    }
}
```

### 6. 默认访问路径配置问题

#### 问题现象
Eclipse自动跳转到错误路径：
```
http://localhost:8080/stuSystem/WEB-INF/studentpages/login.jsp
```

#### 解决方案探索

**尝试1: Eclipse运行配置**
- 打开Run Configurations → Tomcat v9.0 Server
- 但发现**没有URL选项卡**可配置默认路径

**尝试2: 修改index.jsp重定向（成功方案）**
```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%>
<%
    // 自动重定向到登录页面
    response.sendRedirect("user/login");
%>
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>跳转中...</title>
</head>
<body>
    <p>正在跳转到登录页面，请稍候...</p>
    <script>
        // JavaScript备选重定向
        setTimeout(function() {
            window.location.href = "user/login";
        }, 1000);
    </script>
</body>
</html>
```

## 💡 关键经验总结

### 1. 部署验证
- 检查Tomcat日志确认应用部署
- 验证webapps目录下的应用文件夹

### 2. Spring MVC配置
- 组件扫描包路径必须正确
- 视图解析器前缀后缀配置
- `/WEB-INF/` 目录的安全保护

### 3. URL设计原则
- URL路径反映功能结构，而非文件结构
- 保持URL层级一致性
- 通过Controller间接访问JSP

### 4. 数据绑定
- 使用 `@ModelAttribute` 接收表单对象
- 表单字段名与JavaBean属性名匹配
- 添加空值检查防止NPE

### 5. 默认路径配置
- Eclipse运行配置限制较多
- 代码级重定向最可靠
- index.jsp重定向是通用解决方案
