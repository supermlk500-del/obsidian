## 位运算符 >> << >>> 用法详解

### 1. 左移运算符 `<<`
**语法**：`value << num`
**功能**：将 value 的二进制位向左移动 num 位，右侧补 0
**效果**：相当于乘以 2 的 num 次方（在不溢出的情况下）

```java
// 示例
int a = 5;          // 二进制: 00000101
int result = a << 2; // 二进制: 00010100 = 20
System.out.println("5 << 2 = " + result); // 输出: 20

// 计算过程：
// 5 的二进制:  00000000 00000000 00000000 00000101
// 左移2位:    00000000 00000000 00000000 00010100 = 20
```

### 2. 带符号右移运算符 `>>`
**语法**：`value >> num`
**功能**：将 value 的二进制位向右移动 num 位，左侧用符号位填充
- 正数：左侧补 0
- 负数：左侧补 1
**效果**：相当于除以 2 的 num 次方（对于正数且不能整除时向下取整）

```java
// 正数示例
int a = 20;         // 二进制: 00010100
int result1 = a >> 2; // 二进制: 00000101 = 5
System.out.println("20 >> 2 = " + result1); // 输出: 5

// 负数示例
int b = -20;        // 二进制补码表示
int result2 = b >> 2;
System.out.println("-20 >> 2 = " + result2); // 输出: -5

// 计算过程：
// 20 的二进制:  00000000 00000000 00000000 00010100
// 右移2位:     00000000 00000000 00000000 00000101 = 5
```

### 3. 无符号右移运算符 `>>>`
**语法**：`value >>> num`
**功能**：将 value 的二进制位向右移动 num 位，左侧一律补 0
**特点**：不考虑符号位，总是用 0 填充左侧

```java
// 正数示例（与 >> 结果相同）
int a = 20;          // 二进制: 00010100
int result1 = a >>> 2; // 二进制: 00000101 = 5
System.out.println("20 >>> 2 = " + result1); // 输出: 5

// 负数示例（与 >> 结果不同）
int b = -20;         // 二进制补码表示
int result2 = b >>> 2;
System.out.println("-20 >>> 2 = " + result2); // 输出: 1073741819

// 计算过程：
// -20 的补码:  11111111 11111111 11111111 11101100
// 无符号右移2位: 00111111 11111111 11111111 11111011 = 1073741819
```

## 详细对比表格

| 运算符 | 名称 | 功能 | 左侧填充 | 适用场景 |
|--------|------|------|----------|----------|
| `<<` | 左移 | 二进制位左移 | 右侧补0 | 快速乘以2的幂 |
| `>>` | 带符号右移 | 二进制位右移 | 用符号位填充 | 快速除以2的幂，保持符号 |
| `>>>` | 无符号右移 | 二进制位右移 | 总是补0 | 处理无符号数或逻辑移位 |

## 实际应用示例

```java
public class BitShiftExamples {
    public static void main(String[] args) {
        // 1. 快速乘除法
        int x = 10;
        System.out.println(x + " * 4 = " + (x << 2));  // 40, 相当于 10 * 2^2
        System.out.println(x + " / 4 = " + (x >> 2));  // 2, 相当于 10 / 2^2
        
        // 2. 颜色值处理（RGBA）
        int color = 0xFF336699;  // 颜色值
        int red = (color >>> 16) & 0xFF;    // 提取红色分量
        int green = (color >>> 8) & 0xFF;   // 提取绿色分量
        int blue = color & 0xFF;            // 提取蓝色分量
        
        System.out.printf("颜色: #%06X\n", color);
        System.out.printf("RGB: (%d, %d, %d)\n", red, green, blue);
        
        // 3. 权限控制位运算
        int READ = 1;    // 0001
        int WRITE = 2;   // 0010  
        int EXECUTE = 4; // 0100
        
        int userPermissions = READ | WRITE;  // 0011 = 3
        
        // 检查权限
        boolean canRead = (userPermissions & READ) != 0;
        boolean canExecute = (userPermissions & EXECUTE) != 0;
        
        System.out.println("可读: " + canRead);        // true
        System.out.println("可执行: " + canExecute);    // false
    }
}
```

## 注意事项

1. **移位位数限制**：
   - 对于 int 类型，实际移位次数是 `num % 32`
   - 对于 long 类型，实际移位次数是 `num % 64`

2. **数据类型影响**：
```java
byte b = 10;
// b << 2 的结果是 int 类型，需要强制转换
byte result = (byte)(b << 2);
```

3. **溢出问题**：
```java
int max = Integer.MAX_VALUE;  // 2147483647
System.out.println(max << 1); // 溢出，结果为 -2
```

4. **性能优势**：
```java
// 位运算比算术运算更快
int fastMultiply = x << 3;    // 相当于 x * 8
int fastDivide = x >> 3;      // 相当于 x / 8
```

这些位运算符在处理底层数据、性能优化、加密算法等领域有广泛应用。
