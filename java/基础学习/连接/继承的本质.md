# 继承在JVM中的内存布局

## 一、继承对象的完整内存结构

### 1. 简单的继承示例
```java
class Animal {
    // 实例变量
    String name = "动物";
    int age = 1;
    
    // 实例方法
    public void eat() {
        System.out.println("动物吃食物");
    }
}

class Dog extends Animal {
    // 子类特有实例变量
    String breed = "拉布拉多";
    
    // 重写父类方法
    @Override
    public void eat() {
        System.out.println("狗吃狗粮");
    }
    
    // 子类特有方法
    public void bark() {
        System.out.println("汪汪叫");
    }
}
```

## 三、虚方法表 (Virtual Method Table)

### 1. vtable的结构
```
Animal类的虚方法表：
┌─────────────┬─────────────────┬─────────────┐
│  索引(Index) │   方法签名       │  实际地址    │
├─────────────┼─────────────────┼─────────────┤
│      0      │  Object.hashCode│ 0x7f123456 │
│      1      │  Object.equals  │ 0x7f123478 │
│      2      │  Object.toString│ 0x7f12349a │
│      3      │  Animal.eat     │ 0x7f123abc │
└─────────────┴─────────────────┴─────────────┘

Dog类的虚方法表：
┌─────────────┬─────────────────┬─────────────┐
│  索引(Index) │   方法签名       │  实际地址    │
├─────────────┼─────────────────┼─────────────┤
│      0      │  Object.hashCode│ 0x7f123456 │ ← 继承自Object
│      1      │  Object.equals  │ 0x7f123478 │ ← 继承自Object
│      2      │  Object.toString│ 0x7f12349a │ ← 继承自Object
│      3      │  Animal.eat     │ 0x7f654321 │ ← 重写，新地址！
│      4      │  Dog.bark       │ 0x7f765432 │ ← 子类新增方法
└─────────────┴─────────────────┴─────────────┘
```

### 2. 多态方法调用的实现
```java
public class PolymorphismExample {
    public static void main(String[] args) {
        Animal animal = new Dog();  // 向上转型
        animal.eat();  // 动态绑定到Dog.eat()
        
        // JVM内部执行过程：
        // 1. 通过animal引用找到堆中的Dog对象
        // 2. 通过对象头找到Dog.class
        // 3. 在Dog的vtable中查找eat()方法
        // 4. 索引3的位置是Dog.eat()，不是Animal.eat()
        // 5. 调用Dog.eat()方法
    }
}
```

## 四、字段继承的内存布局

### 1. 字段内存排列规则
```java
class A {
    byte a1;      // 1 byte
    int a2;       // 4 bytes
    byte a3;      // 1 byte
}

class B extends A {
    int b1;       // 4 bytes
    byte b2;      // 1 byte
}

// 内存布局优化后（考虑对齐）：
// A对象: [a1(1)+padding(3)] [a2(4)] [a3(1)+padding(3)] = 12 bytes
// B对象: [继承A的12 bytes] [b1(4)] [b2(1)+padding(3)] = 20 bytes
```

### 2. 实际内存布局（JVM会优化）
```
B对象在堆中的实际布局（经过字段重排序）：
┌─────────────────────────────────┐
│ 对象头 (12 bytes)                │
├─────────────────────────────────┤
│ a2 (4 bytes) - int，4字节对齐     │
├─────────────────────────────────┤
│ b1 (4 bytes) - int              │
├─────────────────────────────────┤
│ a1 (1 byte) + a3 (1 byte)       │
│ b2 (1 byte) + padding (1 byte)   │
└─────────────────────────────────┘
总大小: 12 + 4 + 4 + 4 = 24 bytes
```

## 七、继承相关的特殊内存情况

### 1. 静态字段不参与继承的内存布局
```java
class Parent {
    static int staticField = 100;  // 在方法区，不在堆中
    int instanceField = 200;       // 在堆中每个对象实例中
}

class Child extends Parent {
    // staticField不在Child对象的内存布局中
    // 但可以通过Child.staticField访问
}
```

### 2. 私有字段的内存位置
```java
class Parent {
    private String secret = "私有数据";
    
    public String getSecret() {
        return this.secret;  // 可以访问
    }
}

class Child extends Parent {
    public void tryAccess() {
        // System.out.println(secret);  // 编译错误：不可访问
        System.out.println(getSecret());  // 通过公有方法访问
    }
}

// 内存中：secret字段仍然存在于Child对象中
// 只是编译器禁止直接访问
```

## 八、总结：继承在JVM内存中的体现

| 特性 | 内存体现 | 说明 |
|------|---------|------|
| **字段继承** | 子类对象包含父类字段 | 字段在堆中连续存储，父类字段在前 |
| **方法继承** | 通过虚方法表实现 | 子类vtable继承父类vtable并可能修改 |
| **多态** | 运行时查找vtable | 根据实际对象类型调用方法 |
| **访问控制** | 编译时检查 | 不影响内存布局，只影响编译 |
| **静态成员** | 存储在方法区 | 不参与对象内存布局 |
| **构造器链** | 对象头初始化后按父→子顺序 | 确保父类字段先初始化 |

### 关键理解：
1. **"继承"在内存中本质上是字段的叠加**：子类对象 = 父类所有实例字段 + 子类新增字段
2. **方法是共享的**：所有实例共享方法区的代码，通过虚方法表区分
3. **多态通过查表实现**：调用方法时，根据对象实际类型查找对应的vtable
4. **内存布局会优化**：JVM可能重新排列字段以减少内存浪费
5. **访问控制是编译时概念**：private字段仍在子类对象中，只是不能直接访问

### 实际验证代码：
```java
public class InheritanceMemoryTest {
    public static void main(String[] args) {
        // 创建子类对象
        Dog dog = new Dog();
        
        // 验证父类字段存在
        System.out.println("父类字段 age: " + dog.age);  // 输出: 1
        
        // 验证方法表
        Animal animalRef = dog;  // 向上转型
        animalRef.eat();  // 输出: "狗吃狗粮" - 证明调用的是Dog的方法
        
        // 通过反射查看所有字段（包括私有）
        Field[] fields = dog.getClass().getDeclaredFields();
        System.out.println("\nDog类所有字段:");
        for (Field field : fields) {
            System.out.println(field.getName() + ": " + field.getType());
        }
    }
}
```

继承在JVM中是一种高效的内存共享和代码复用机制，通过精心设计的内存布局和虚方法表，实现了面向对象的核心特性。

# 多层继承中同名变量访问规则

## 一、示例代码分析

```java
class GrandParent {
    String name = "GrandParent的名字";
}

class Parent extends GrandParent {
    String name = "Parent的名字";  // 隐藏了父类的name
}

class Child extends Parent {
    String name = "Child的名字";   // 隐藏了父类的name
    
    public void printNames() {
        // 问题：这里访问的是哪个name？
        System.out.println("直接访问: " + name);
        System.out.println("this.name: " + this.name);
        System.out.println("super.name: " + super.name);
        
        // 如何访问GrandParent的name？
        // System.out.println(super.super.name);  // 错误！不支持这种语法
    }
}
```

## 二、实际访问规则

### 1. 直接访问的情况
```java
public class Test {
    public static void main(String[] args) {
        Child child = new Child();
        child.printNames();
    }
}
```
**输出结果：**
```
直接访问: Child的名字
this.name: Child的名字
super.name: Parent的名字
```

### 2. 内存布局示意图
```
Child对象在堆内存中：
┌─────────────────────────────────┐
│ 对象头                           │
├─────────────────────────────────┤
│ GrandParent.name                 │  <- 值为"GrandParent的名字"
│   (引用类型，4字节)               │
├─────────────────────────────────┤
│ Parent.name                      │  <- 值为"Parent的名字"
│   (隐藏字段，独立存储)             │
├─────────────────────────────────┤
│ Child.name                       │  <- 值为"Child的名字"
│   (隐藏字段，独立存储)             │
└─────────────────────────────────┘
```

**重要：** 三个`name`字段在内存中**同时存在**，只是访问路径不同！

## 三、访问规则详解

### 规则1：就近原则（最重要）
```java
class Child extends Parent {
    String name = "Child的名字";
    
    void test() {
        System.out.println(name);      // 输出: "Child的名字" (Child的name)
        System.out.println(this.name); // 输出: "Child的名字" (Child的name)
    }
}
```

### 规则2：使用super访问直接父类
```java
class Child extends Parent {
    String name = "Child的名字";
    
    void test() {
        System.out.println(super.name); // 输出: "Parent的名字"
        // 只能访问直接父类Parent的name
        // 无法直接访问GrandParent的name
    }
}
```

### 规则3：通过转型访问祖先类的字段
```java
class Child extends Parent {
    String name = "Child的名字";
    
    void test() {
        // 方法1：通过强制转型
        Parent parentView = this;
        System.out.println(((Parent)this).name);  // "Parent的名字"
        System.out.println(((GrandParent)this).name); // "GrandParent的名字"
        
        // 方法2：创建父类引用
        GrandParent gp = new Child();
        System.out.println(gp.name);  // "GrandParent的名字"
    }
}
```

## 四、完整的访问示例

```java
public class MultiLevelInheritanceDemo {
    public static void main(String[] args) {
        Child child = new Child();
        
        System.out.println("=== 不同方式访问name ===");
        System.out.println("1. child.name: " + child.name);  // Child的名字
        
        // 通过不同类型的引用访问
        Parent parentRef = child;
        System.out.println("2. parentRef.name: " + parentRef.name);  // Parent的名字
        
        GrandParent gpRef = child;
        System.out.println("3. gpRef.name: " + gpRef.name);  // GrandParent的名字
        
        // 强制转型
        System.out.println("4. (Parent)child.name: " + ((Parent)child).name);  // Parent的名字
        System.out.println("5. (GrandParent)child.name: " + ((GrandParent)child).name);  // GrandParent的名字
        
        // 在Child类内部访问
        child.printAllNames();
    }
}

class GrandParent {
    String name = "GrandParent的名字";
}

class Parent extends GrandParent {
    String name = "Parent的名字";
}

class Child extends Parent {
    String name = "Child的名字";
    
    public void printAllNames() {
        System.out.println("\n=== 在Child类内部访问 ===");
        System.out.println("1. name: " + name);  // Child的名字
        System.out.println("2. this.name: " + this.name);  // Child的名字
        System.out.println("3. super.name: " + super.name);  // Parent的名字
        
        // 无法直接访问GrandParent的name，需要技巧
        System.out.println("4. ((Parent)this).name: " + ((Parent)this).name);  // Parent的名字
        System.out.println("5. ((GrandParent)this).name: " + ((GrandParent)this).name);  // GrandParent的名字
        
        // 通过中间变量访问
        Parent p = this;
        GrandParent gp = this;
        System.out.println("6. p.name: " + p.name);  // Parent的名字
        System.out.println("7. gp.name: " + gp.name);  // GrandParent的名字
    }
}
```

**输出结果：**
```
=== 不同方式访问name ===
1. child.name: Child的名字
2. parentRef.name: Parent的名字
3. gpRef.name: GrandParent的名字
4. (Parent)child.name: Parent的名字
5. (GrandParent)child.name: GrandParent的名字

=== 在Child类内部访问 ===
1. name: Child的名字
2. this.name: Child的名字
3. super.name: Parent的名字
4. ((Parent)this).name: Parent的名字
5. ((GrandParent)this).name: GrandParent的名字
6. p.name: Parent的名字
7. gp.name: GrandParent的名字
```

## 五、访问机制的原理

### 1. 字段隐藏 vs 方法重写
```java
class A {
    String value = "A的字段";
    void print() { System.out.println("A的方法"); }
}

class B extends A {
    String value = "B的字段";  // 字段隐藏：两个value同时存在
    void print() { System.out.println("B的方法"); }  // 方法重写：只有一个print
}

public class Test {
    public static void main(String[] args) {
        B b = new B();
        A a = b;
        
        System.out.println(b.value);  // "B的字段" - 字段：看引用类型
        System.out.println(a.value);  // "A的字段" - 字段：看引用类型
        
        b.print();  // "B的方法" - 方法：看实际对象类型
        a.print();  // "B的方法" - 方法：看实际对象类型
    }
}
```

### 2. 编译时决定 vs 运行时决定
```java
class Example {
    // 字段访问：编译时根据引用类型决定
    // 编译时：a.value -> 编译为访问A类的value字段
    // 编译时：b.value -> 编译为访问B类的value字段
    
    // 方法调用：运行时根据实际对象类型决定
    // 编译时：a.print() -> 编译为虚方法调用
    // 运行时：查找虚方法表，调用实际对象的方法
}
```

## 六、最佳实践建议

### 1. 避免字段隐藏（推荐做法）
```java
// 不推荐：使用字段隐藏
class Base {
    protected String name;  // 容易造成混淆
}

class Derived extends Base {
    private String name;  // 隐藏了父类的name，容易出错
}

// 推荐：使用方法访问
class Base {
    private String name;
    
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}

class Derived extends Base {
    // 不定义name字段，使用父类的
    // 或者如果要扩展，用不同的名字
    private String nickName;
}
```

### 2. 如果需要多层访问，使用protected方法
```java
class GrandParent {
    private String name = "GrandParent";
    
    protected String getGrandParentName() {
        return this.name;
    }
}

class Parent extends GrandParent {
    private String name = "Parent";
    
    protected String getParentName() {
        return this.name;
    }
}

class Child extends Parent {
    private String name = "Child";
    
    public void printAll() {
        System.out.println("Child: " + name);
        System.out.println("Parent: " + getParentName());
        System.out.println("GrandParent: " + getGrandParentName());
    }
}
```

## 七、总结

1. **三个`name`字段同时存在**在内存中
2. **直接访问时**：访问当前类定义的字段（就近原则）
3. **使用`super`时**：只能访问直接父类的字段
4. **通过类型转换**：可以访问任何祖先类的字段 `((GrandParent)this).name`
5. **字段隐藏与方法重写不同**：
   - 字段：根据引用类型在编译时决定
   - 方法：根据实际对象类型在运行时决定
6. **最佳实践**：避免字段隐藏，使用方法访问器

在您的三层继承结构中，当在最下面的子类中直接访问`name`时，访问的是**当前子类自己定义的`name`字段**。要访问父类或祖父类的同名字段，需要使用类型转换或提供专门的访问方法。
