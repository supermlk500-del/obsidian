
## 一、什么是模板设计模式（Template Method Pattern）

一句话定义（⭐ 必背）：

> **在抽象类中定义算法骨架，把具体步骤延迟到子类实现。**

📌 核心思想：

- **流程不变**
    
- **细节可变**
    

---

## 二、生活直觉理解（非常重要）

🌰 例子：**做菜**

步骤固定：

1. 洗菜
    
2. 做菜
    
3. 出锅
    

但是：

- 炒土豆
    
- 炒白菜
    
- 炒肉
    

👉 **流程一样，做菜细节不一样**

---

## 三、模板设计模式的结构（记住这 3 个点）

### 1️⃣ 抽象类（模板类）

- 定义 **模板方法（流程）**
    
- 定义 **抽象方法（细节）**
    

### 2️⃣ 模板方法

- **普通方法**
    
- 里面调用抽象方法
    
- 一般不让子类改（可以用 `final`）
    

### 3️⃣ 子类

- 只负责实现抽象方法
    

---

## 四、最经典 Java 示例（强烈建议敲一遍）

### ① 抽象类：模板

```java
// 抽象类
abstract class Job {

    // 模板方法：流程固定
    public final void execute() {
        start();
        work();     // 抽象方法
        end();
    }

    protected void start() {
        System.out.println("开始工作");
    }

    // 抽象方法：子类实现
    protected abstract void work();

    protected void end() {
        System.out.println("结束工作");
    }
}
```

📌 注意：

- `execute()` 是 **模板方法**
    
- `work()` 是 **变化点**
    

---

### ② 子类 1

```java
class Programmer extends Job {
    @Override
    protected void work() {
        System.out.println("程序员在写代码");
    }
}
```

---

### ③ 子类 2

```java
class Teacher extends Job {
    @Override
    protected void work() {
        System.out.println("老师在上课");
    }
}
```

---

### ④ 测试

```java
public class Test {
    public static void main(String[] args) {
        Job job1 = new Programmer();
        job1.execute();

        System.out.println("--------");

        Job job2 = new Teacher();
        job2.execute();
    }
}
```

### 👉 输出结果

```
开始工作
程序员在写代码
结束工作
--------
开始工作
老师在上课
结束工作
```

## 五、为什么模板方法一般是 `final`？（面试常问）

```java
public final void execute() {
    start();
    work();
    end();
}
```

📌 原因：

> **防止子类破坏整体流程**

子类只能改“细节”，不能改“顺序”。

## 六、再来一个「韩顺平风格」的例子（考试感很强）

### 🌰 统计不同程序的执行时间

#### 抽象类

```java
abstract class Template {

    public final void calculateTime() {
        long start = System.currentTimeMillis();
        job();
        long end = System.currentTimeMillis();
        System.out.println("耗时：" + (end - start));
    }

    public abstract void job();
}
```

#### 子类

```java
class Task1 extends Template {
    @Override
    public void job() {
        for (int i = 0; i < 100000; i++) {
            Math.sqrt(i);
        }
    }
}
```

```java
class Task2 extends Template {
    @Override
    public void job() {
        for (int i = 0; i < 100000; i++) {
            Math.pow(i, 2);
        }
    }
}
```

## 七、模板设计模式的优点（⭐）

1. **代码复用**（公共流程写一次）
    
2. **结构清晰**（流程 + 细节分离）
    
3. **符合开闭原则**（新增功能只加子类）
    

---

## 八、什么时候用模板设计模式？

📌 满足这 3 个条件就用：

- 有 **固定流程**
    
- 某些步骤 **不同**
    
- 希望 **子类只改细节**
    

---

## 九、一句话终极总结（考试 / 面试用）

> **模板设计模式：在抽象类中定义算法骨架，把可变部分交给子类实现。**
