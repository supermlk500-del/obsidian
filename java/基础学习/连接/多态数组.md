**多态数组**是指：**数组的元素类型是父类（或接口），但实际存储的是子类对象**。这是 Java 多态（Polymorphism）在数组中的典型应用。

---

### ✅ 核心特点

- **声明时用父类/接口类型**；
- **运行时每个元素可以是任意子类实例**；
- **调用方法时，自动触发动态绑定**（执行子类重写后的方法）；
- **不能直接调用子类特有方法**（除非向下转型）。

---

### 📌 精简示例（符合你之前的风格）

```java
class Animal {
    int i = 1;
    int getI() { return i; }
    void speak() { System.out.println("Animal"); }
}

class Dog extends Animal {
    int i = 2;
    @Override
    int getI() { return i; }
    @Override
    void speak() { System.out.println("Dog"); }
    void wagTail() { System.out.println("Wag tail"); } // 子类特有
}

class Cat extends Animal {
    int i = 3;
    @Override
    int getI() { return i; }
    @Override
    void speak() { System.out.println("Cat"); }
}

public class PolyArray {
    public static void main(String[] args) {
        // 多态数组：编译类型为 Animal，实际存 Dog、Cat 对象
        Animal[] animals = new Animal[3];
        animals[0] = new Animal();
        animals[1] = new Dog();
        animals[2] = new Cat();

        // 遍历调用重写方法 → 动态绑定生效
        for (Animal a : animals) {
            System.out.println(a.getI()); // 输出: 1, 2, 3
            a.speak();                    // 输出: Animal, Dog, Cat
        }

        // ❌ 编译错误：父类引用不能直接调用子类特有方法
        // animals[1].wagTail();

        // ✅ 正确方式：向下转型（需先判断类型）
        if (animals[1] instanceof Dog) {
            ((Dog) animals[1]).wagTail(); // 输出: Wag tail
        }
    }
}
```

---

### 🔍 关键点说明

| 行为 | 说明 |
|------|------|
| `Animal[] animals = new Animal[3];` | 声明一个**父类类型的数组** |
| `animals[1] = new Dog();` | 实际存入**子类对象**（向上转型） |
| `a.getI()` / `a.speak()` | **动态绑定**：根据实际对象类型调用对应方法 |
| `a.i`（如果访问字段） | **静态绑定**：始终访问 `Animal` 的 `i`（不推荐直接访问字段） |
| 调用 `wagTail()` | 必须**向下转型** + `instanceof` 安全检查 |

---

### ⚠️ 注意事项

1. **数组本身是协变的**（Covariant）  
   - `Dog[]` 是 `Animal[]` 的子类型（这在泛型中不成立，但数组允许）；
   - 但运行时会做类型检查，防止存入非法类型：

   ```java
   Animal[] arr = new Dog[2];
   arr[0] = new Cat(); // 运行时抛出 ArrayStoreException！
   ```

2. **多态数组常用于统一处理不同子类对象**  
   比如：图形系统中 `Shape[]` 存 `Circle`、`Rectangle`，统一调用 `draw()`。

3. **字段不具备多态性**  
   如果你访问 `a.i`，永远得到父类的 `i`，所以**应通过 getter 方法访问**（如 `getI()`）。

---

### ✅ 总结

> **多态数组 = 父类引用数组 + 子类对象实例 + 动态绑定方法调用**

它是实现“**统一接口，多种实现**”的重要手段，广泛应用于框架设计和业务逻辑中。
