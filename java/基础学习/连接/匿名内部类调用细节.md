## 调用细节——匿名内部类既是“类的定义”，也是“对象的创建”

### 一句话先记住（核心）

> **匿名内部类：在定义一个类的同时，立刻创建这个类的对象，而且这个类没有名字**

---

## 为什么说它“既像定义类，又像创建对象”？

先看一个**普通写法**，你会马上明白差异。

---

## 对比 1：普通方式（类 + 对象分开）

### 定义接口

```java
interface Usb {
    void connect();
}
```

### 定义实现类

```java
class Mouse implements Usb {
    @Override
    public void connect() {
        System.out.println("鼠标连接");
    }
}
```

### 创建对象并调用

```java
Usb usb = new Mouse();
usb.connect();
```

---

## 对比 2：匿名内部类写法（重点）

```java
Usb usb = new Usb() {
    @Override
    public void connect() {
        System.out.println("匿名内部类实现的连接");
    }
};
```

### 调用

```java
usb.connect();
```

---

## 🔍 逐行拆解理解（非常重要）

```java
Usb usb = new Usb() {
    @Override
    public void connect() {
        System.out.println("匿名内部类实现的连接");
    }
};
```

### 这行代码同时做了 **两件事**

#### ① 定义了一个“没有名字的类”

```java
class ??? implements Usb {
    public void connect() {
        System.out.println("匿名内部类实现的连接");
    }
}
```

#### ② 立刻 new 了这个类的对象

```java
new ???();
```

👉 **定义类 + 创建对象 = 一步完成**

---

## 为什么它“只能用一次”？

- 匿名内部类 **没有类名**
    
- 无法再次 `new`
    
- 适合：**只用一次的临时实现**

## 匿名内部类的本质结构（脑中模型）

```java
接口类型  变量名 = new 接口() {
    // 重写接口的抽象方法
};
```

或者

```java
父类类型  变量名 = new 父类() {
    // 重写父类方法
};
```

---

## 再来一个“当参数用”的经典例子（非常常见）

### 接口

```java
interface Usb {
    void connect();
}
```

### 方法

```java
class Computer {
    public void work(Usb usb) {
        usb.connect();
    }
}
```

### 使用匿名内部类作为参数

```java
Computer computer = new Computer();

computer.work(new Usb() {
    @Override
    public void connect() {
        System.out.println("匿名内部类作为参数");
    }
});
```

### 这句代码的含义

```java
new Usb() {
    ...
}
```

👉 **不是接口对象（接口不能 new）**  
👉 而是：**一个实现了 Usb 的匿名类对象**

## 再对比一个：lambda 前的真实写法（理解用）

```java
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("线程执行中");
    }
};

new Thread(r).start();
```

👉 这就是 lambda 出现之前最经典的匿名内部类用法

## 编译类型 & 运行类型（考试爱考）

```java
Usb usb = new Usb() {
    @Override
    public void connect() {
        System.out.println("hello");
    }
};
```

- **编译类型**：`Usb`
    
- **运行类型**：匿名内部类（JVM 自动生成的类）
    

---

## 匿名内部类使用限制（顺带记）

1. 没有构造器
    
2. 不能写访问修饰符
    
3. 不能定义静态成员
    
4. 只能使用一次
    
5. 可以访问外部类的成员（含 private）
    

---

## 一句话终极总结（直接写进笔记）

> **匿名内部类 = 没有名字的子类 / 实现类  
> 在定义类的同时完成对象创建  
> 本质是一个“临时一次性对象”**
