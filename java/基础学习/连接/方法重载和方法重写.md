Java 中的**方法重载（Overloading）**和**方法重写（Overriding）**是两个容易混淆但本质不同的概念。它们的主要区别如下：

---

### 一、定义不同

- **方法重载（Overloading）**  
  在**同一个类**中，允许存在多个**同名方法**，只要它们的**参数列表不同**（参数类型、个数或顺序不同），就构成方法重载。

- **方法重写（Overriding）**  
  在**子类**中，对**父类中已有的方法**进行重新定义（实现），要求方法名、参数列表、返回类型（或其子类型）完全相同。

---

### 二、发生位置不同

- **重载**：发生在**同一个类内部**。
- **重写**：发生在**父子类之间**（继承关系）。

---

### 三、参数列表要求

- **重载**：**必须不同**（类型、数量或顺序至少有一项不同）。
- **重写**：**必须完全相同**。

---

### 四、返回类型要求

- **重载**：可以不同（但不是判断重载的依据）。
- **重写**：
  - Java 5 及以前：必须相同；
  - Java 5+：允许返回类型为**协变类型**（即子类方法的返回类型可以是父类方法返回类型的子类）。

---

### 五、访问修饰符

- **重载**：无限制。
- **重写**：子类方法的访问权限**不能比父类更严格**（例如父类是 `protected`，子类可以是 `public`，但不能是 `private` 或默认）。

---

### 六、异常处理

- **重载**：无限制。
- **重写**：子类方法**不能抛出比父类方法更宽泛的检查型异常**（checked exception），但可以抛出更窄的或不抛出。

---

### 七、绑定时机（多态）

- **重载**：**编译时多态**（静态绑定）—— 编译器根据调用时的参数类型决定调用哪个方法。
- **重写**：**运行时多态**（动态绑定）—— JVM 在运行时根据对象的实际类型决定调用哪个方法。

---

### 示例代码

```java
// 方法重载示例
class Calculator {
    int add(int a, int b) {
        return a + b;
    }
    
    double add(double a, double b) {
        return a + b;
    }
}

// 方法重写示例
class Animal {
    void speak() {
        System.out.println("Animal speaks");
    }
}

class Dog extends Animal {
    @Override
    void speak() {
        System.out.println("Dog barks");
    }
}
```

---

### 总结对比表

| 特性             | 方法重载（Overloading）       | 方法重写（Overriding）         |
|------------------|-------------------------------|--------------------------------|
| 发生位置         | 同一个类                      | 父子类之间                     |
| 方法名           | 相同                          | 相同                           |
| 参数列表         | 必须不同                      | 必须相同                       |
| 返回类型         | 可不同（不影响重载）          | 必须相同或为协变类型           |
| 访问修饰符       | 无限制                        | 子类不能更严格                 |
| 异常             | 无限制                        | 不能抛出更宽的 checked 异常    |
| 多态类型         | 编译时多态                    | 运行时多态                     |
