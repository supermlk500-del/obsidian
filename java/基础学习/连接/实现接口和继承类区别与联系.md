## 一、一句话先给结论（先有整体认知）

> **继承（extends）**：是 **“是不是” 的关系（is-a）**，强调**代码复用 + 父子关系**  
> **实现接口（implements）**：是 **“能不能” 的关系（can-do）**，强调**能力、规范、扩展**

---

## 二、最直观对比表（考试 + 面试常用）

| 对比点    | 继承类（extends） | 实现接口（implements）             |
| ------ | ------------ | ---------------------------- |
| 关系本质   | is-a（是什么）    | can-do（能做什么）                 |
| 数量限制   | **只能继承一个类**  | **可以实现多个接口**                 |
| 是否有构造器 | 有            | **没有构造器**                    |
| 成员变量   | 可以有实例变量      | 只能是 `public static final` 常量 |
| 方法实现   | 可以有具体方法      | 抽象方法为主（Java 8+ 可有默认方法）       |
| 代码复用   | **强**        | 弱（主要是规范）                     |
| 设计目的   | 复用 + 扩展      | 约束 + 解耦                      |
| 是否有状态  | 有            | 一般无状态                        |

---

## 三、继承（extends）——重点理解

### 1️⃣ 本质：is-a 关系

```java
class Animal {
    public void eat() {
        System.out.println("动物吃东西");
    }
}

class Dog extends Animal {
}
```

👉 **Dog is an Animal**（成立）  
👉 适合用继承

### 2️⃣ 特点总结

- 子类**自动拥有**父类的非 private 成员
    
- 强耦合（子类依赖父类实现）
    
- 适合**父类非常稳定**的场景
    

### 3️⃣ 不能乱用继承（非常重要）

❌ 错误示例：

```java
class Car extends Engine  // ❌
```

Car **不是** Engine，而是 **has-a（拥有）**

---

## 四、接口（implements）——重点理解

### 1️⃣ 本质：can-do 能力

```java
interface Flyable {
    void fly();
}

class Bird implements Flyable {
    public void fly() {
        System.out.println("鸟会飞");
    }
}
```

👉 Bird **能飞**，不是 Bird is Flyable

---

### 2️⃣ 接口是“规范 / 协议”

```java
interface USB {
    void connect();
}

class Mouse implements USB {
    public void connect() {
        System.out.println("鼠标连接");
    }
}

class Keyboard implements USB {
    public void connect() {
        System.out.println("键盘连接");
    }
}
```

👉 **调用方只关心 USB，不关心具体实现**

```java
public void useUSB(USB usb) {
    usb.connect();
}
```

这就是 **解耦 + 多态** 的核心价值。

## 五、为什么 Java 只能单继承，却能多实现接口？

### ❓ 问题本质

如果允许多继承：

```java
class A { void f(){} }
class B { void f(){} }

class C extends A, B  // ❌
```

👉 `f()` 调谁？**二义性问题**

### ✅ Java 的解决方案

- **类：单继承**（避免冲突）
    
- **接口：多实现**（接口本身不含状态）
    

---

## 六、继承 和 接口 的“联系”（很重要）

### 1️⃣ 它们都支持多态

```java
Animal a = new Dog();     // 继承多态
USB u = new Mouse();      // 接口多态
```

👉 **编译看左边，运行看右边**

---

### 2️⃣ 抽象类可以实现接口（但不实现方法）

```java
interface A {
    void f();
}

abstract class B implements A {
    // 可以不实现 f()
}
```

👉 因为 **抽象类本身不要求完整实现**

---

### 3️⃣ 继承 + 接口 = Java 最常见设计

```java
class Person { }

interface Runnable {
    void run();
}

class Student extends Person implements Runnable {
    public void run() {
        System.out.println("学生在跑");
    }
}
```

---

## 七、什么时候用继承？什么时候用接口？（面试必问）

### ✅ 用继承 when：

- 明确的 **is-a 关系**
    
- 需要**代码复用**
    
- 父类相对稳定
    

👉 例：`Dog extends Animal`

---

### ✅ 用接口 when（更常用）：

- 需要 **多实现**
    
- 需要 **解耦**
    
- 面向接口编程（Spring 核心思想）
    

👉 例：  
`UserServiceImpl implements UserService`

---

## 八、一句话终极总结（背下来）

> **继承：强调“你是什么”**  
> **接口：强调“你能干什么”**  
> **Java 中：优先用接口，慎用继承**
