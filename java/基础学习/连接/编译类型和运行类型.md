**在 Java（以及其他面向对象语言）中，“**编译类型**”和“**运行类型**”是理解**多态**（尤其是方法重写）的关键概念。

---

### 一、定义

- **编译类型**（Compile-time type / Static type）  
  是变量在**代码编写时声明的类型**，由编译器在编译阶段确定。  
  例如：`Animal a = new Dog();` 中，`a` 的编译类型是 `Animal`。

- **运行类型**（Runtime type / Dynamic type / Actual type）  
  是变量在**程序运行时实际指向的对象的类型**。  
  上例中，`a` 实际指向的是 `Dog` 对象，因此运行类型是 `Dog`。

---

### 二、关键区别

| 方面   | 编译类型           | 运行类型            |
| ---- | -------------- | --------------- |
| 决定时机 | 编译时（写代码时）      | 运行时（程序执行时）      |
| 决定依据 | 变量声明的类型        | `new` 创建的实际对象类型 |
| 影响内容 | 能调用哪些方法（合法性检查） | 实际执行哪个方法（动态绑定）  |

---

### 三、示例说明

```java
class Animal {
    void speak() { System.out.println("Animal"); }
}

class Dog extends Animal {
    @Override
    void speak() { System.out.println("Dog"); }
    
    void wagTail() { System.out.println("Wagging tail"); }
}

public class Main {
    public static void main(String[] args) {
        Animal a = new Dog(); // 编译类型：Animal；运行类型：Dog
        
        a.speak();      // 输出 "Dog" —— 方法重写，动态绑定
        // a.wagTail(); // 编译错误！编译类型 Animal 没有 wagTail 方法
    }
}
```

- **为什么 `a.speak()` 输出 "Dog"？**  
  因为 `speak()` 被重写了，JVM 在运行时根据**运行类型**（`Dog`）调用对应的方法。

- **为什么不能调用 `wagTail()`？**  
  因为编译器只看**编译类型**（`Animal`），而 `Animal` 类中没有 `wagTail()` 方法，所以编译失败。

---

### 四、与多态的关系

- **编译类型决定“能不能调用”**（语法合法性）。
- **运行类型决定“实际执行哪个实现”**（动态分派）。

这就是 Java **运行时多态**的核心机制。

---

### 五、如何获取运行类型？

可以通过 `getClass()` 方法查看对象的实际类型：

```java
Animal a = new Dog();
System.out.println(a.getClass()); // 输出：class Dog
```

---

### 总结

- **编译类型** = 变量左边的类型（声明类型）→ **静态，编译期确定**。
- **运行类型** = `new` 后面的类（实际对象类型）→ **动态，运行期确定**。
- 方法调用：
  - **重载** → 看编译类型（静态绑定）。
  - **重写** → 看运行类型（动态绑定）。
