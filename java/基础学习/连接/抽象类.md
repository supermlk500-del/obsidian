## 一、什么是抽象类（Abstract Class）

**抽象类**就是：

> **不能被直接创建对象，只能被继承的类**

它用来描述一类“**不完整的事物**”，给子类提供**统一规范**。

📌 关键字：`abstract`

```java
abstract class 类名 {
}
```

---

## 二、为什么要有抽象类？

举个生活例子 🌰：

> 动物都会“叫”，  
> 但你没法说“动物怎么叫”。

```java
Animal a = new Animal(); // ❌ 不合理
```

所以我们只定义 **规范**，具体怎么叫，交给子类实现。

---

## 三、抽象类的特点（重点记忆 ⭐）

### 1️⃣ 抽象类不能创建对象

```java
abstract class Animal {}

Animal a = new Animal(); // ❌ 编译错误
```

---

### 2️⃣ 抽象类可以有 **抽象方法**

抽象方法：**只有方法声明，没有方法体**

```java
abstract class Animal {
    public abstract void speak();
}
```

📌 抽象方法也必须用 `abstract`

---

### 3️⃣ 抽象类也可以有 **普通方法**

```java
abstract class Animal {
    public void eat() {
        System.out.println("动物在吃东西");
    }
}
```

👉 所以：

> **抽象类 ≠ 全是抽象方法**

---

### 4️⃣ 子类必须实现所有抽象方法（否则子类也得是抽象类）

```java
class Dog extends Animal {
    @Override
    public void speak() {
        System.out.println("狗在汪汪叫");
    }
}
```

如果不实现：

```java
class Dog extends Animal {
    // ❌ 报错
}
```

---

### 5️⃣ 抽象类可以有构造器（但不能 new）

```java
abstract class Animal {
    public Animal() {
        System.out.println("Animal 构造器");
    }
}
```

👉 构造器是 **给子类用的**，不是给自己 new 的。

---

## 四、完整示例（非常重要，建议敲一遍）

```java
// 抽象类
abstract class Animal {
    String name;

    public Animal(String name) {
        this.name = name;
    }

    // 抽象方法
    public abstract void speak();

    // 普通方法
    public void eat() {
        System.out.println(name + " 在吃东西");
    }
}

// 子类
class Dog extends Animal {
    public Dog(String name) {
        super(name);
    }

    @Override
    public void speak() {
        System.out.println(name + " 汪汪叫");
    }
}

// 测试类
public class Test {
    public static void main(String[] args) {
        Animal dog = new Dog("小黑"); // 向上转型
        dog.speak();
        dog.eat();
    }
}
```

🧠 这体现了：

- 抽象类
    
- 继承
    
- 方法重写
    
- 多态

## 五、抽象类 vs 普通类（对比表 ⭐）

|对比点|抽象类|普通类|
|---|---|---|
|是否能 new|❌ 不能|✅ 能|
|是否有抽象方法|✅ 可以|❌ 不可以|
|是否有普通方法|✅ 可以|✅ 可以|
|是否能被继承|✅ 是|✅ 是|

---

## 六、抽象类 vs 接口（先简单理解）

|项目|抽象类|接口|
|---|---|---|
|关键字|abstract class|interface|
|继承/实现|extends|implements|
|构造器|✅ 有|❌ 没有|
|成员变量|普通变量|public static final|
|适合场景|is-a 关系|规范/能力|

📌 **现在阶段重点掌握抽象类即可**，接口后面学。

---

## 七、一句话总结（考试/面试常考）

> **抽象类用于定义规范，不能实例化，子类必须实现其抽象方法。**
