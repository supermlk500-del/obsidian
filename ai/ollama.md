# 为ollama设置代理

在 **CMD** 里用：

```cmd
setx HTTP_PROXY http://127.0.0.1:7890
setx HTTPS_PROXY http://127.0.0.1:7890
setx ALL_PROXY socks5://127.0.0.1:7890
```

然后：

1. 关闭当前终端
2. 重新打开终端
3. **重启 Ollama**
4. 再执行 `ollama pull ...`

### 一句话

- **CMD 用 `set` / `setx`**
- **PowerShell 才用 `$env:HTTP_PROXY=...`**

你现在直接复制这三行就行：

```cmd
set HTTP_PROXY=http://127.0.0.1:7890
set HTTPS_PROXY=http://127.0.0.1:7890
ollama pull qwen2.5:7b-instruct
```




这三句是在 **给 Windows 设置代理环境变量**，让命令行程序也知道“上网要走代理”。

分别是：

```cmd
setx HTTP_PROXY http://127.0.0.1:7890
```
意思是：
- 给 **HTTP 请求** 设置代理
- 代理地址是你本机的 `127.0.0.1:7890`

```cmd
setx HTTPS_PROXY http://127.0.0.1:7890
```
意思是：
- 给 **HTTPS 请求** 设置代理
- 大多数下载模型其实主要靠这个

```cmd
setx ALL_PROXY socks5://127.0.0.1:7890
```
意思是：
- 给“其他支持通用代理的程序”设置默认代理
- 这里用的是 **SOCKS5 代理**

---

### `setx` 是什么意思？
`setx` = **永久写入环境变量**

也就是说它不是只对当前窗口有效，而是写到系统/用户环境里。
所以你设置完后：

- **新开的终端**会生效
- 有些后台程序要**重启**后才会吃到新变量

---

### `127.0.0.1:7890` 又是什么意思？
- `127.0.0.1` = 你自己的电脑
- `7890` = 代理软件开的本地端口

也就是：
> “把网络请求先发给我本机 7890 这个代理端口，再由代理出去联网”

通常这就是 Clash、v2rayN、sing-box 之类软件开的端口。

---

### 和 `set` 的区别
- `set`：**只对当前 CMD 窗口临时生效**
- `setx`：**永久生效**

比如：

```cmd
set HTTP_PROXY=http://127.0.0.1:7890
```

这个只在当前窗口有效，关掉就没了。

---

### 你可以把它理解成
这三句就是在告诉系统：

- 下载普通网页时，走这个代理
- 下载加密网页时，走这个代理
- 其他支持通用代理的程序，也优先走这个代理
