# 统计建模大赛 · 修订版完整工作步骤

> 论文题目（当前正式版本）
> **检验生成式AI驱动内容营销对消费升级的影响，并比较不同消费升级测度下结论的差异**
>
> 当前核心思路：
> 不再强行证明“AI推荐贡献最大”，而是基于已经完成的数据处理和模型结果，重点识别生成式AI驱动内容营销对消费升级的影响，并解释为什么这一结论会随着消费升级测度方式的变化而发生差异。

---

## 一、当前研究定位

这项研究现在已经不再是“先设计一个理想故事，再去找结果”的状态，而是：

**先把数据和模型完整跑通，再根据真实结果重组论文叙事。**

当前已经得到的事实是：

1. 基准模型下，核心内容营销变量整体不强
2. 当消费升级改用“人均线上消费支出”衡量时，模型结果明显增强
3. `X1` 的替代变量稳健性没有明显强化原始强命题
4. `Shapley` 没有统一支持“AI贡献最大”
5. 互联网普及率和城镇化率会显著放大 AI 触达效应
6. 门槛回归和空间扩展提供了补充亮点
7. DID 已完成，但因果识别证据偏弱

因此，当前论文主线应明确写成：

**生成式AI驱动内容营销对消费升级的影响具有测度敏感性。**

## 三、核心概念界定

### 1. 生成式AI

本文中的“生成式AI”不只指狭义文本生成模型，而是指在数字平台内容营销场景中，能够提升内容生成、内容分发和用户匹配效率的技术体系，主要包括：

- AI推荐算法：以短视频平台 MAU 作为代理变量，衡量平台算法触达规模
- AIGC渗透：以 2022 年后政策虚拟变量作为代理变量，衡量生成式AI在内容生产中的结构性进入

### 2. 内容营销

本文将内容营销理解为“以内容为载体的用户触达与转化链条”，并拆分为四个维度：

| 维度 | 代理变量 | 层次 |
|------|----------|------|
| AI触达 | 短视频MAU | 内容分发层 |
| AIGC渗透 | 政策虚拟变量 | 内容生产层 |
| 数字广告投放 | 广告规模 | 付费分发层 |
| 直播带货转化 | 直播GMV | 内容转化层 |

### 3. 消费升级

本文不再只把消费升级理解为“线上渠道占比提升”，而是同时使用两个口径：

| 变量 | 含义 | 作用 |
|------|------|------|
| `Y` | 线上消费渗透率 | 基准因变量 |
| `Y_alt1` | 人均线上消费支出 | 替代因变量 |

这样做的原因是：

**消费升级并不是单一概念，不同测度方式会影响结论。**

## 五、当前模型体系

### 前置检验

已完成：

- 多重共线性检验
- 平稳性检验
- Hausman 规格检验
- 相关系数分析

### 模型1：双向固定效应基准回归

回答的问题：

**四类内容营销变量是否对消费升级存在独立影响？**

公式设定：

```text
Y_it = α + β1X1_it + β2X2_it + β3X3_it + β4X4_it + γZ_it + μ_i + λ_t + ε_it
```

其中：
- `Y_it` 为消费升级指标（线上消费渗透率或人均线上消费支出）
- `X1_it` 为短视频平台 MAU
- `X2_it` 为 AIGC 政策虚拟变量
- `X3_it` 为数字广告投放规模
- `X4_it` 为直播带货转化规模
- `Z_it` 为控制变量组
- `μ_i` 为省份固定效应，`λ_t` 为年份固定效应

### 稳健性检验

已完成三条路径：

1. 替换因变量：`Y → Y_alt1`
2. 替换自变量：`X1 → 短视频渗透率`
3. 异常值敏感性：对 `Y_alt1` 缩尾

回答的问题：

**结论是否依赖某一种变量定义或极端值？**

### 模型2：Shapley 贡献分解

回答的问题：

**不同变量在模型解释力中各自贡献多少？**

公式设定：

```text
φ_j = Σ_{S⊆M\{j}} [ |S|!(|M|-|S|-1)! / |M|! ] · [ R²(S∪{j}) - R²(S) ]
```

其中：
- `M={X1,X2,X3,X4}` 为核心解释变量集合
- `φ_j` 表示变量 `X_j` 的 Shapley 贡献值
- `R²(S)` 表示仅包含变量子集 `S` 时模型的解释度

当前使用方式：

不再用于强证“AI贡献最大”，而用于展示不同消费升级测度下贡献结构会发生变化。

### 模型3：调节效应

分别检验：

- 互联网普及率调节
- 城镇化率调节
- 物流效率调节

回答的问题：

**什么条件会放大 AI 触达效应？**

公式设定：

```text
Y_it = α + β1X1_it + β2M_it + β3(X1_it × M_it) + γZ_it + μ_i + λ_t + ε_it
```

其中：
- `M_it` 分别表示互联网普及率、城镇化率或物流效率
- `β3` 为交互项系数，用于识别条件变量是否会放大或削弱 `X1` 的影响

### 模型4：空间溢出探索

回答的问题：

**AI触达和消费升级是否存在跨省扩散效应？**

公式设定：

```text
Y_it = ρWY_it + βX_it + θWX_it + γZ_it + μ_i + λ_t + ε_it
```

其中：
- `W` 为空间权重矩阵
- `ρ` 为空间滞后系数
- `θ` 为空间溢出系数
- `WX_it` 表示相邻地区内容营销变量的加权影响

### 模型5：门槛回归

回答的问题：

**互联网普及率是否存在使 AI 效应变化的门槛值？**

公式设定：

```text
Y_it = α + β1X1_it·I(q_it≤γ) + β2X1_it·I(q_it>γ) + δZ_it + μ_i + λ_t + ε_it
```

其中：
- `q_it` 为门槛变量，这里取互联网普及率
- `γ` 为待估计门槛值
- `I(·)` 为示性函数
- `β1`、`β2` 分别表示门槛两侧 `X1` 的作用强度

### 模型6：DID 因果识别尝试

回答的问题：

**AIGC 冲击是否具有更强的因果解释力？**

公式设定：

```text
Y_it = α + β1Treat_i + β2Post_t + β3(Treat_i × Post_t) + γZ_it + μ_i + λ_t + ε_it
```

其中：
- `Treat_i` 为处理组虚拟变量
- `Post_t` 为政策实施后时期虚拟变量
- `Treat_i × Post_t` 为 DID 交互项
- `β3` 用于识别 AIGC 冲击的净效应

## 六、当前真实结果

### 1. 基准模型结果

- 以 `Y=线上消费渗透率` 为因变量时，核心内容营销变量整体作用偏弱
- 当前基准模型中更稳定的显著项主要是部分控制变量

这说明：

**原始强命题在基准模型下支撑不足。**

### 2. 替代因变量结果

- 当将因变量替换为 `Y_alt1=人均线上消费支出` 后，模型解释力和显著性明显增强
- `log(Y_alt1)` 的结果最强

这说明：

**生成式AI驱动内容营销的影响，在“人均线上支出提升”口径下更容易被识别。**

### 3. 替代自变量结果

- 把 `X1` 换成短视频渗透率后，结果没有明显增强

这说明：

**X1 代理变量测度仍然存在局限，但并没有因此推翻现有主线。**

### 4. 异常值敏感性结果

- 对 `Y_alt1` 做缩尾后，结论整体仍较强

这说明：

**替代因变量结果并非完全由极端值驱动。**

### 5. Shapley 结果

- 不同消费升级测度下，贡献最大的变量并不一致

这说明：

**不同消费升级测度下，变量贡献结构本身也会变化。**

### 6. 调节效应结果

- 互联网普及率 × AI触达：显著为正
- 城镇化率 × AI触达：显著为正
- 物流效率 × AI触达：不显著

这说明：

**互联网基础设施和城镇化水平会显著放大 AI 触达效应。**

### 7. 空间扩展结果

- 存在一定跨省扩散特征

### 8. 门槛回归结果

- 门槛值约为 `0.4307`
- 门槛两侧 `X1` 的系数均为正，但强度不同

### 9. DID 结果

- DID 交互项不显著

这说明：

**当前因果识别证据偏弱，DID 更适合写成“因果识别尝试”。**

---

## 七、当前最稳妥的论文结论

当前最符合现有证据的结论应写成：

**生成式AI驱动内容营销对消费升级的影响具有测度敏感性。在以线上消费渗透率衡量消费升级时，核心内容营销变量的作用相对有限；在以人均线上消费支出衡量消费升级时，内容营销变量，尤其是AI触达变量的作用更容易被识别。同时，互联网普及率与城镇化水平会显著放大AI触达效应，且该效应还表现出一定的空间扩散和门槛特征。**

## 八、当前仍需注意的问题

### 1. 不能再写“AI推荐贡献最大”

因为：

- Shapley 没有统一支持
- 基准模型也没有形成足够强的支撑

### 2. DID 不能写成强因果

因为：

- 当前交互项不显著
- 只能写成“因果识别尝试”

### 3. 门槛回归不能硬写成“低组无效、高组跳升”

因为当前真实结果是：

- 低组和高组都显著
- 只是系数强度不同

### 4. 暂时不写预测部分

原因是：

- 当前还没有形成一套完整、可直接放进论文的预测与情景推演结果
- 与其保留空壳，不如先把实证主线写实
