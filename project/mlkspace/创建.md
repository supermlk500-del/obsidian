## pom.xml : 记得把这个文件添加为maven文件
![[依赖.png]]
- 这里要选择合适的启动依赖等东西,当然后面也可以自行增加
![[依赖1.png]]
```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.5.15</version>
    <relativePath/>
</parent>
```
- 它的作用是帮你统一管理 Spring Boot 相关依赖版本、插件版本、默认编译配置。

## 依赖
### 参数校验
- 每一个 `<dependency>` 都是一个外部库。
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-validation</artifactId>
</dependency>
```
- 作用是可以在DTO上写校验注解
###  web接口依赖
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```
- 作用是可以写REST API
- 它包含 Spring MVC、JSON 序列化、内置 Tomcat 等。没有这个，后端就不能正常提供 HTTP 接口
### 这个是 MySQL 驱动
```xml
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```
- 作用是让 Spring Boot 能连接 MySQL 数据库。你的数据库名是 `mlkspace`，后面 `application.yml` 会通过这个驱动连接它。
### 这个是 Lombok
```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
</dependency>
```
- 作用是减少 Java 样板代码
